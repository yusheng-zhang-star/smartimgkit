Detailed User Guide

Step 1: Adjust the Shadow Settings

Use the sliders for Offset X, Offset Y, Blur, Spread and Opacity, and pick a colour. Offset moves the shadow's position, Blur softens its edges, Spread grows or shrinks it, and Opacity controls how visible it is.

Step 2: Set the Border Radius

Adjust the top-left, top-right, bottom-right and bottom-left corners independently to round the element's corners to the exact curve you want.

Step 3: Copy the CSS

The generated box-shadow and border-radius values update as you drag. Copy them and paste into your stylesheet or inline style.

Understanding the Output

The box-shadow syntax is offset-x offset-y blur spread color, which matches the standard CSS box-shadow property. The border-radius outputs each corner in clockwise order starting from the top-left.

How the Preview Stays in Sync

Every slider is bound to a live handler that recomputes the CSS string and redraws the preview element on input. There is no compile step and no submit button — the values you see are the exact values in the generated code, so there is nothing to lose in translation between preview and output.

Troubleshooting and Limitations

The generator focuses on a single box shadow and rounded corners; it does not stack multiple shadows or output a full gradient declaration (the preview background is gradient for demonstration only). If a shadow looks different in your project than in the preview, check that no parent style is overriding the values, and that you copied the colour's alpha channel along with the RGB values.

Who Uses a CSS Generator

Front-end developers prototype shadows and corners quickly instead of guessing values in the inspector. Designers hand off exact values to developers without ambiguity. Students and hobbyists learn how box-shadow parameters interact by seeing the result change in real time.
