Batch Rename Images

This page builds new names from a prefix, an optional separator and a zero-padded counter, keeps each file's original extension, and hands back one ZIP containing the renamed copies — the files on your disk are not touched. Numbering follows the order the files arrived in, and there is no sort control, so the preview list is the only place to check the sequence.

    How to rename many images at once

    1. Add your images. Drag in a folder's worth of files — there is no batch limit.
    2. Set the prefix. Something descriptive like iceland-2026 beats IMG when you search your library months later.

    4. Check the preview and download. If the names look right, download the ZIP and unpack it in place of the originals.

    Detailed User Guide

    Why rename in the browser at all

    Browsers cannot rename files on disk directly for security reasons, so this tool rebuilds your files under new names and hands them back as a ZIP. Nothing is uploaded, and your originals remain intact.

    Handle large photo sets without limits

    There is no hard batch limit, so you can rename hundreds of travel or event photos in one go. The ZIP download groups them all so you only have to unpack once.

    Combine with compression before uploading

    Renaming is often the first step before a larger workflow — pair the renamed files with a batch compressor or resizer if the destination has size limits.

    Separator choice affects readability

    A hyphen gives holiday-001.jpg, an underscore gives holiday_001.jpg, and none gives holiday001.jpg. Hyphens and underscores are both safe in filenames; the choice is mostly aesthetic.

    Start number lets you continue a sequence

    If you already renamed a batch ending at 099, set the next batch to start at 100 to continue the sequence seamlessly instead of restarting from 001.

    Avoid special characters in the prefix

    Stick to letters, numbers, hyphens, and underscores in the prefix. Spaces and symbols can break filenames on some systems, cloud drives, and CMS uploads.

    Why the ZIP instead of renaming in place

    A browser cannot overwrite files on your disk for security reasons, so the tool returns renamed copies in a ZIP. Unzip them into the target folder and delete the originals to complete the swap.

    Useful for CMS and gallery uploads

    Platforms and galleries often prefer sequential, lowercase, descriptive filenames over default camera names like IMG_0047. A clean batch makes managing uploaded media far easier.

    Padding digits keep files sorted correctly

    Choosing the number of digits controls zero-padding. Three digits covers up to 999 files (001, 002, …), while four digits keeps the order correct for larger sets in any file manager.

    Extensions are always preserved

    Each file keeps its original extension, so renamed JPGs stay JPGs and PNGs stay PNGs. You never risk breaking a format during the rename.

    A shared prefix is a searchable label

    A consistent prefix plus sequential numbering is what galleries, CMS uploads, and print labs expect. Months later, iceland-2026-047 is far easier to find than IMG_0047.

    Numbering follows the order you added files

    Files are numbered in the order they appear in the preview list, which is the order you added them. Add everything in one drop to keep that order predictable.

    Frequently Asked Questions

    Does this rename the files on my computer?

    No browser can change filenames on disk for security reasons. The tool produces renamed copies inside a ZIP; unzip it and delete the originals if you want a clean swap.

    What order are files numbered in?

    In the order you added them — the same order shown in the preview list. Add files in one drop to keep that order predictable.

    Can I include the original filename?

    Not in this version. The output is always prefix + separator + number, which is what most galleries, CMS uploads and print labs expect.

    Are my photos uploaded?

    No. Everything is processed in your browser; the images never leave your device.

    Can I sort the files before numbering?

    No. The list is displayed in arrival order and there is no sort, drag or reverse control, so the sequence is whatever the file dialog or the drop handed over. Dropping a folder usually produces alphabetical order from the browser, but mixed sources are unpredictable — rename in separate runs per source.

    Are my original files renamed on disk?

    No. Browsers cannot rename files, so the page reads each file, attaches it to a new name inside a ZIP, and downloads that archive. Your originals stay exactly where they were with their old names, which is also why keeping them is a reasonable safety net.

    What happens to the file extension?

    It is taken from the original name and lowercased, so a .JPG becomes .jpg and a .PNG stays .png. The prefix and counter replace only the part before the dot. A file with no dot in its name is given the extension img, which is worth checking for before you download.

    Which characters are allowed in the prefix?

    Backslash, slash, colon, asterisk, question mark, double quote, angle brackets and the pipe character are each replaced with an underscore, because they are illegal or dangerous in Windows file names. Spaces and accented letters pass through untouched, which can trip up older tools downstream.

    What if two files end up with the same name?

    They cannot. Every file in the batch gets its own index, so the counter alone keeps the names unique, and the prefix is identical by design. What can look wrong instead is alignment: with two digits allowed, the hundredth file is padded no further and prints as photo-100 rather than photo-99, so the sort order in a file manager stops being alphabetical.
