Batch Rename Images

Give dozens of photos a consistent name in one go — a shared prefix plus sequential numbering (holiday-001.jpg, holiday-002.jpg…). Renaming happens locally and the results arrive as a ZIP.

📝

Drop multiple images here or click to choose files

JPG, PNG, WebP, GIF, BMP, AVIF or SVG

Add images, then set the naming pattern. The preview updates as you type.

    Why rename in the browser?

    Browsers cannot rename files on disk directly, so this tool does the next best thing: it rebuilds your files under the new names and hands them back as a single ZIP. Your originals stay untouched, and nothing is uploaded to a server.

    🔢 Sequential numbering

    Choose the starting number and how many digits to pad with, so files sort correctly in any file manager.

    🔒 Local only

    The files are read and re-zipped entirely in your browser — ideal for personal photos you would rather not upload.

    👀 Live preview

    The exact new name is shown next to every file before you commit, so there are no surprises.

    🧩 Extensions preserved

    Each file keeps its original extension, so renamed JPGs stay JPGs and PNGs stay PNGs.

    How to rename many images at once

    1. Add your images. Drag in a folder's worth of files — there is no batch limit.
    2. Set the prefix. Something descriptive like iceland-2026 beats IMG when you search your library months later.
    3. Pick the numbering. Three digits covers up to 999 files; use four for larger sets so the order stays correct.
    4. Check the preview and download. If the names look right, download the ZIP and unpack it in place of the originals.

    Frequently Asked Questions

    Does this rename the files on my computer?

    No browser can change filenames on disk for security reasons. The tool produces renamed copies inside a ZIP; unzip it and delete the originals if you want a clean swap.

    What order are files numbered in?

    In the order you added them — the same order shown in the preview list. Add files in one drop to keep that order predictable.

    Can I include the original filename?

    Not in this version. The output is always prefix + separator + number, which is what most galleries, CMS uploads and print labs expect.

    Are my photos uploaded?

    No. Everything is processed in your browser; the images never leave your device.
