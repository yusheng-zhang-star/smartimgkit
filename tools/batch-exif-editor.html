Batch EXIF Date Editor

    What this tool does — and does not do

    It rewrites the three EXIF date fields (DateTime, DateTimeOriginal, DateTimeDigitized) in your JPEG files. The pixels are untouched, so there is no re-compression and no quality loss.

    ✔ Rewrites the capture date

    All three date tags are set to the value you pick, so photo managers, Lightroom, Apple Photos and Google Photos all sort by the same date.

    ✔ Keeps other metadata

    Camera model, lens, ISO, GPS and keywords are preserved — only the date fields change.

    ✔ No re-compression

    The JPEG image stream is copied byte for byte, so file size and quality stay exactly the same.

    ✖ Not a GPS or serial editor

    This page changes dates only. To strip metadata entirely, use the EXIF Remover instead.

    How to change the date on multiple photos

    1. Add your JPGs. Drag in as many files as you like — nothing is uploaded, so a large batch is fine.
    2. Check the current dates. Each file shows the capture date already in its EXIF block, so you can spot the ones that need fixing.
    3. Pick the new date and time. Both the date and the clock time are written, so you can also correct a camera that was set to the wrong time zone.
    4. Click Apply & Download. One photo downloads directly; several are packed into a single ZIP. Originals on disk are never modified — you get edited copies named …-edited.jpg.

    Frequently Asked Questions

    Which file types are supported?

    JPEG only. EXIF dates are a JPEG/TIFF feature — PNG, WebP and GIF files do not carry a capture date, so they are skipped automatically.

    Will this reduce image quality?

    No. Only the small EXIF header segment is rewritten; the compressed image data is copied unchanged.

    Can I set different dates for different photos?

    Not in one pass. Set one date for the whole batch, download the results, then run the ones that need a different date a second time.

    Does my photo get uploaded?

    Never. Everything runs in your browser using a local copy of the piexif library. You can disconnect from the internet after the page has loaded and the tool still works.

    How do I undo it?

    Save the originals before you overwrite them. This tool downloads edited copies and never touches the files on your disk, so your originals stay intact.
