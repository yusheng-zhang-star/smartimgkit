Detailed User Guide

Step 1: Upload Your Image

Load a bitmap. High-contrast images — black-and-white logos, line art, icons — trace far better than detailed photos, which produce messy paths.

Step 2: Adjust Threshold and Detail

The threshold controls the lightness cut-off between what becomes a filled shape and what is ignored. The detail (turdsize) slider removes tiny speckles below a size you set, cleaning up noise in the trace.

Step 3: Download the SVG

Export the result as a true SVG file with vector paths you can scale and edit in any vector program.

How the Vectorisation Works

The image is downscaled to a workable size and traced with a local Potrace engine, which converts the bitmap's black-and-white regions into closed vector paths. The output is genuine SVG geometry — not a bitmap wrapped in an SVG tag.

Troubleshooting and Limitations

Photos with soft gradients trace poorly because vector tracing works best on clean two-tone shapes; keep the source high-contrast for the best result. The threshold and detail controls affect the whole image globally, so very busy images may need a clean-up pass in a vector editor afterwards.

Who Uses Image to SVG

Brand designers vectorise logos that only exist as a bitmap, laser-cutting shops convert artwork to cuttable paths, and developers trace icons to make them resolution-independent for the web.

Preparing an Image for a Clean Trace

The single biggest factor in trace quality is contrast. Before uploading, convert your source to pure black on white and remove noise, shadows and gradients. A crisp, high-contrast logo traces into a handful of clean paths, while a grainy scan produces hundreds of tiny flecks that need cleanup. Start with a high threshold and lower it only if the trace misses parts of the design.
