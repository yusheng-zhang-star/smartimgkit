Guia Detalhada

Passo 1: Enviar sua Imagem

Envie qualquer imagem JPG, PNG ou WebP. Funciona muito bem com fotos, arte, capturas de tela ou qualquer imagem com cores interessantes.

Envie uma imagem e escolha quantas cores dominantes extrair

Passo 2: Escolher Quantidade de Cores

Use o controle para selecionar quantas cores extrair (3–12). Mais cores dão uma paleta mais rica; menos cores dão um esquema mais focado e minimalista.

  • 3-4 cores — ideal para branding simples e designs minimalistas
  • 5-6 cores — paleta equilibrada para a maioria dos projetos web e de UI
  • 8-12 cores — paleta completa para designs complexos e ilustrações

Passo 3: Extrair e Usar

Clique em "Extrair Cores" para analisar a imagem. A ferramenta exibe:

  • Amostras de cores com valores HEX e RGB
  • Variáveis CSS prontas para copiar direto para sua folha de estilo

Clique em qualquer amostra de cor para copiar seu código HEX para a área de transferência instantaneamente.

Dica: a primeira cor costuma ser a mais dominante. Use-a como cor principal da marca e as demais como acentos e neutros.

Melhores Casos de Uso

  • Inspiração de cores da marca — extraia cores de um mood board ou imagem de referência
  • Tematização do site — combine a paleta do site com uma foto-chave ou imagem de produto
  • Design de UI — gere esquemas de cores acessíveis para apps e dashboards
  • Arte e ilustração — construa paletas harmoniosas a partir de fotos da natureza ou obras

Dicas Profissionais

  • Imagens com cores fortes e distintas produzem as melhores paletas
  • Use a saída CSS diretamente no :root do seu projeto para tematização consistente
  • Experimente extrair de várias imagens e combinar paletas para resultados únicos
  • O algoritmo encontra cores visualmente dominantes, não apenas estatisticamente frequentes
