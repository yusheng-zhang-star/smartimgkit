Guia Detalhado

Passo 1: Envie uma Imagem Quadrada

Arraste e solte uma imagem quadrada. PNG com transparência funciona melhor.

Passo 2: Escolha os Tamanhos

Marque os tamanhos desejados. O arquivo ICO conterá exatamente os tamanhos selecionados.

Passo 3: Ajuste a Renderização

Configure algoritmo de escala, cantos arredondados, cor de fundo e preenchimento.

Passo 4: Pré-visualização

Cada tamanho selecionado é renderizado na grade de pré-visualização.

Passo 5: Baixar

Clique em "Baixar ICO" para um único arquivo, ou "Baixar ZIP" para todos os tamanhos em PNG.

Formato de Arquivo ICO

ICO é um formato de contêiner que pode armazenar múltiplos tamanhos de imagem em um único arquivo. Cada entrada é uma imagem completa (ICO moderno usa PNG).

Perguntas Frequentes
