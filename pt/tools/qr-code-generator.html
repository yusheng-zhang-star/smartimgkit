Guia Detalhada

Passo 1: Escolher tipo de conteúdo

Selecione um de: URL, Texto, WiFi, vCard ou Email.

Passo 2: Preencher o conteúdo

Insira os dados relevantes para o tipo escolhido.

Passo 3: Personalizar aparência

Ajuste cores de primeiro plano/fundo, nível de correção de erro e tamanho.

Passo 4: Adicionar logo central (opcional)

Carregue um PNG, JPG ou SVG para colocar no centro do código QR.

Passo 5: Baixar

Clique "Baixar PNG" para raster ou "Baixar SVG" para vetor.

Passo 6: Lote (opcional)

Clique "Adicionar ao lote" para enfileirar outro código QR, depois baixe todos como ZIP.

Níveis de correção de erro

  • L (7%) — Código menor
  • M (15%) — Padrão
  • Q (25%) — Com logo
  • H (30%) — Máxima robustez
