Guia Detalhado

Qual versão escolher

v4 é a escolha padrão: 122 bits puramente aleatórios, aceito universalmente. v7 começa com um carimbo de tempo milissegundo, então os identificadores ordenam cronologicamente — isso reduz a reorganização de índices em bancos de dados e facilita ordenar registros sem coluna de data. v1 usa carimbo + endereço MAC da máquina; raramente vale a pena hoje, justamente porque expõe o hardware.

Como a aleatoriedade é gerada

A ferramenta usa crypto.getRandomValues(), o gerador criptográfico do navegador (CSPRNG) — não o Math.random(), que é previsível. v7 combina o carimbo de tempo com bits do CSPRNG. Ambas as versões são seguras para uso onde imprevisibilidade importa, como tokens de referência.

Probabilidade de colisão

Um UUID v4 tem 2122 possibilidades. Gerando um bilhão de UUIDs por segundo, ainda levaria décadas para existir chance realista de repetição. Na prática: para IDs de registro, trate como únicos e gaste preocupação com outra coisa. A quantidade máxima por clique (10.000) existe apenas para não travar a renderização da caixa de texto.

Formatos e compatibilidade

As chaves {...} são o estilo de GUID do Windows (registro, Active Directory). Maiúsculas e minúsculas são equivalentes: compare sempre ignorando caixa. Remover os hífens mantém os 32 caracteres hexadecimais — formato comum em URLs curtas e nomes de arquivo. Ajuste os três interruptores antes de gerar para já receber o formato final.

Casos de uso no Brasil

Identificador de pedido em e-commerce antes do número sequencial existir, idempotency-key em cobranças Pix via API (evitar cobrança duplicada em retentativa), chaves de deduplicação em planilhas e pipelines de dados, e IDs que não expõem quantos cadastros já existem — diferentemente de sequências numéricas 1, 2, 3…

UUID não é segredo

Um UUID v4 é imprevisível, mas não é um segredo nem um token de autorização: se uma URL funcionar apenas porque contém o UUID, qualquer pessoa que vazar esse valor acessa o recurso. Use UUID como identificador e mantenha a autorização em outro lugar — sessão, permissão ou assinatura. Geradores que prometem "IDs secretos" criam uma falsa sensação de segurança pior do que não ter senha nenhuma.

Privacidade

A geração é local: crypto.getRandomValues() roda no seu navegador e nenhum UUID trafega para servidores. Cole os identificadores onde precisar sem se preocupar com registro.
