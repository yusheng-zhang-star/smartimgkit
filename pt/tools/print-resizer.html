Guia Detalhada

Passo 1: Enviar sua Imagem

Clique na área de upload ou arraste e solte uma imagem. Formatos suportados: JPG, PNG, WebP. A imagem carrega instantaneamente — nada é enviado para nenhum servidor.

Passo 2: Escolher Tamanho do Papel

Selecione entre predefinições de impressão comuns:

  • A4 (210×297 mm): padrão internacional, o mais comum no mundo
  • Carta (8,5×11"): padrão dos EUA, comum na América do Norte
  • A5 (148×210 mm): metade do A4, para folhetos e panfletos pequenos
  • 4×6" (10×15 cm): tamanho padrão de foto impressa
  • 5×7" (13×18 cm): foto maior, comum em molduras
  • Cartão de Visita (3,5×2"): tamanho padrão de cartão dos EUA
  • Personalizado: informe largura e altura em polegadas

Passo 3: Definir DPI (Pontos por Polegada)

DPI determina a qualidade de impressão:

  • 72 DPI: resolução de tela, não recomendado para impressão
  • 150 DPI: aceitável para impressões de grande formato vistas de longe
  • 300 DPI: padrão para fotos impressas de alta qualidade (recomendado)
  • 600 DPI: impressão profissional, arquivos muito grandes

Regra prática: Para impressões de fotos, use sempre 300 DPI. Para banners grandes vistos a mais de 3m de distância, 150 DPI é suficiente.

Passo 4: Baixar

Clique em Baixar para salvar sua imagem pronta para impressão. PNG é recomendado para qualidade máxima; JPG com qualidade 92+ também é aceitável para fotos.

Melhores Casos de Uso

  • Fotos impressas: A4 ou 4×6" a 300 DPI → JPG
  • Cartões de visita: predefinição Cartão de Visita a 300 DPI → PNG
  • Pôsteres/banners: tamanho personalizado a 150 DPI → PNG
  • Documentos: Use Letter ou A4 a 300 DPI → JPG
  • Impressões artísticas: A4/A5 a 600 DPI → PNG (qualidade máxima)

Dicas Profissionais

  • Para fotos em laboratório, exporte sempre a 300 DPI no espaço de cor sRGB
  • A4 a 300 DPI = 2480×3508 pixels — verifique se sua imagem original é pelo menos desse tamanho
  • Se a imagem original for menor que o alvo em DPI, o resultado será ampliado (perda de qualidade) — use antes nosso Image Upscaler
  • Para impressão jato de tinta em casa, 300 DPI é mais que suficiente — 150 DPI fica quase idêntico
  • Salve como JPG com qualidade 92-95 para impressos; use PNG apenas para preservar texto nítido ou arte linear
