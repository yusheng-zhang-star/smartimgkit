Guia Detalhado

Qual JSON a ferramenta aceita

Somente JSON padrão (RFC 8259): chaves e strings com aspas duplas, sem comentários e sem vírgula sobrando no fim de listas. JSON5 e JSONC (com // ou chaves sem aspas, comum em tsconfig.json) não são aceitos — remova os comentários antes de validar.

Formatar ou minificar?

Formatar (2 ou 4 espaços) é para leitura: revisar configurações, comparar versões em diff, documentar payloads. Minificar remove todo espaço — é o formato para produção, quando cada byte do corpo da requisição conta. A escolha entre 2 e 4 espaços é convenção do time; projetos JavaScript costumam seguir 2.

Como ler as mensagens de erro

A validação usa o JSON.parse do navegador, que aponta a posição exata do problema: "Unexpected token } in JSON at position 42" significa que o caractere 42 da sua string é o primeiro lugar onde o parse quebrou — o erro real costuma estar logo antes dele. Os campeões de ocorrência: vírgula depois do último item, aspas simples no lugar de duplas e chaves ou colchetes não fechados.

Casos de uso no Brasil

Inspecionar o corpo de webhooks de pagamento (Pix, gateways como Mercado Pago e PagSeguro), conferir payloads de integração com ERPs e e-commerces, formatar arquivos de configuração de deploy e entender respostas de API antes de abrir chamado com o fornecedor.

Erros comuns ao colar JSON

Três armadilhas que vêm de fora do JSON:

  • Excel converte valores ao colar: códigos longos viram notação científica e datas mudam de formato — cole em editor de texto puro primeiro.
  • Aspas tipográficas (" ") de textos formatados não são JSON válido — substitua por aspas retas (").
  • BOM: arquivos salvos no Bloco de Notas podem começar com o caractere invisível U+FEFF, que quebra o parse — recrie o arquivo em UTF-8 sem BOM.

Um fluxo seguro antes de ir para produção

Rotina que evita incidentes: cole a resposta bruta da API e clique em ✓ Validar — se estiver válido, formate e leia a estrutura de verdade (quantos níveis, quais campos opcionais vêm null). Só então escreva o código que consome esses campos. Metade dos bugs de integração nasce de uma premissa errada sobre o formato da resposta — um campo que às vezes é string e às vezes número, por exemplo. O validador não corrige isso por você, mas mostrar o JSON legível deixa a premissa errada visível em segundos.

Privacidade e limites

Nada é enviado a servidores: a formatação usa funções nativas do navegador. Recomendamos até ~10 MB para manter a resposta fluida — payloads gigantes de log podem travar a aba. Mesmo assim, evite colar JSON com dados pessoais reais de clientes quando um exemplo ofuscar serve.
