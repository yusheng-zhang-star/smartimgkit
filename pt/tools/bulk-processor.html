How to Use the Bulk Image Processor

Batch process dozens of images in under a minute. Here's how:

1

Drop or Select Images

Drag and drop multiple image files, or click the upload area to browse. You can select as many files as you need.

2

Choose a Preset or Customize

Pick a quick preset (Web Optimized, Print Ready, E-Commerce, Thumbnail) or expand "Processing Options" for full control over resize, format, quality, and watermark.

3

Configure Batch Rename

Toggle "Rename output files" to set a naming pattern with prefix and auto-numbering (e.g. product_001.jpg).

4

Click Process All

Click the "Process All" button. Each file shows its own progress bar, and you'll see live before/after size comparisons.

5

Download ZIP Archive

Review the results, check compression savings, then click "Download ZIP" to get all processed images in one file.

Guia Detalhada

Batch Resize

Insira a largura e/ou altura desejada na seção Redimensionar. Com "Manter proporção" marcado (padrão), a ferramenta calcula automaticamentely scales the other dimension. Leave both empty to keep original dimensions. This is perfect for normalizing product photos or creating uniform social media assets.

Dica: Se você inserir apenas a largura, a altura se ajusta automaticamente para manter as proporções — sem necessidade de cálculos.

Batch Compress & Convert

Use o menu suspenso Formato de Saída para converter todas as imagens para JPG, PNG ou WebP. JPG é a melhor opção para fotografiass (small file size), PNG preserves transparency, and WebP offers modern compression. The Quality slider (10-100%) lets you balance file size versus visual quality — 80-85% is the sweet spot for web use.

Dica: WebP geralmente pode reduzir o tamanho do arquivo em 25-35% em comparação com JPG no mesmo nível de qualidade.

Batch Watermark

Digite o texto da marca d'água, ajuste o tamanho da fonte e a opacidade, e escolha uma posição (inferior direito, inferior esquerdo, superior direito, superior esquerdot, or center). Leave the text field blank to skip watermarks. Great for branding batch photos before publishing.

Dica: Mantenha a opacidade entre 20-40% para uma marca d'água profissional e não intrusiva.

Batch Rename

Ative "Renomear arquivos de saída" e defina um prefixo e número inicial. Os arquivos serão nomeados sequencialmente: prefixo_001.ext, prefix_002.ext, etc. The numbering is zero-padded (3 digits by default).

Dica: Use prefixos descritivos como produto_, galeria_ ou foto_ for easy file organization.

Using Presets

Clique em qualquer botão de predefinição para configurar vários ajustes de uma vez instantaneamente:

  • Web Optimized — 80% quality, max 1200px width. Ideal for blog images, portfolio thumbnails, and website assets.
  • Print Ready — 100% quality, max 3000px. Best for photo printing, high-res archiving, and professional deliverables.
  • E-Commerce — 85% quality, max 1000px. Optimized for product listings on marketplaces like Amazon, eBay, or Shopify.
  • Thumbnail — 60% quality, max 300px. Perfect for preview images, avatars, or gallery thumbnails.

Após aplicar uma predefinição, você ainda pode ajustar as configurações individuais no painel de Opções de Processamento.
