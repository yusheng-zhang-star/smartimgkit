Comment tester une expression régulière

1

Écrivez le motif

Saisissez votre regex dans le champ Motif ; les résultats se mettent à jour à chaque frappe, sans bouton à cliquer.

2

Cochez les réglages

Activez g pour toutes les correspondances, i pour ignorer la casse, m pour traiter chaque ligne séparément et s pour que le point couvre aussi les retours à la ligne.

3

Collez le texte de test

Le texte sur lequel valider le motif va dans le champ de test, tel que vous le trouverez dans votre contenu réel.

4

Lisez les résultats

Chaque correspondance est surlignée dans le texte et listée avec sa position et ses groupes de capture.

Ce que fait et ne fait pas le testeur

Test en direct, sans bouton

Chaque frappe relance l’évaluation : motif à gauche, texte à droite, et le panneau de résultats affiche déjà les correspondances surlignées. Rien à enregistrer, rien à envoyer — corrigez le motif et le résultat suit immédiatement.

Les quatre drapeaux et leur effet

g cherche toutes les correspondances au lieu de s'arrêter à la première ; i traite majuscules et minuscules comme identiques ; m fait fonctionner les ancres de début et fin de ligne sur chaque ligne ; s autorise le point à couvrir les retours à la ligne. Sans g, une seule correspondance s'affiche, même si le texte en contient vingt.

La liste détaille position et groupes

Chaque correspondance est listée avec son indice dans le texte et ses groupes de capture numérotés. C'est ce qui permet de déboguer un motif à groupes alternatifs : on voit d'un coup d'œil quel groupe a capturé quel fragment.

Le dialecte est JavaScript, pas PCRE

Le moteur est le RegExp du navigateur (ES2018 et suivants) : lookbehind, groupes nommés et propriétés Unicode fonctionnent, mais des différences fines subsistent avec PCRE en PHP ou le module re de Python. Un motif validé ici marchera presque toujours en JavaScript navigateur ou Node ; pour les autres langages, vérifiez à part.

Les erreurs de motif s'affichent telles quelles

Une expression invalide — parenthèse non fermée, quantificateur orphelin — déclenche le message d'erreur du moteur lui-même, en rouge. Ce libellé vient de JavaScript : le rechercher tel quel dans la documentation vous donne l'explication exacte.

Nos usages de la semaine

Mettre au point le motif qui valide l'adresse d'un formulaire, extraire des références ou des dates d'un listing copié depuis une annonce, ou nettoyer un fichier exporté en collant le texte et en ajustant le motif jusqu'à ce que l'aperçu surligne exactement ce qu'on veut capturer.

Confidentialité et limites

Tout s'évalue dans le navigateur : motif et texte ne partent nulle part. Rien n'est conservé — recharger la page efface motif et texte —, pas de bibliothèque de motifs, et les textes très longs mettent un peu plus de temps à être évalués.

Cinq réflexes pour gagner du temps

  • Collez un échantillon réel, pas un mot inventé. Un motif qui marche sur « abc » échoue souvent sur une adresse, un numéro ou un libellé réel.
  • Isolez le problème. Si votre motif complet dysfonctionne, réduisez-le à sa partie incriminée, validez-la, puis rajoutez les fragments un par un.
  • Vérifiez les drapeaux. g, i, m, s changent tout : un oubli de g explique neuf cas de « correspondance manquante ».
  • Copiez le motif validé tel quel. Les groupes nommés et les ancres s'exportent sans transformation vers JavaScript navigateur ou Node.
  • Notez votre motif dans un commentaire de projet. La page oublie tout à la fermeture : le copier ailleurs est la seule mémoire persistante.

RGPD : tester un motif sur des données réelles sans les transmettre

Le Référentiel général sur la protection des données, en France comme dans l'Union européenne, impose une règle simple : les données personnelles ne doivent pas circuler vers des services qui n'en ont pas l'utilité. Or le débogage d'expressions régulières demande souvent des échantillons réels : listes de clients, extraits de factures, adresses postales, numéros de téléphone. Coller ces données dans un outil en ligne est une habitude risquée, et ce testeur est conçu précisément pour éviter ce détournement.

Tout se passe dans le navigateur. Le moteur RegExp du navigateur évalue votre motif localement : aucune requête sortante, aucune journalisation, aucune conservation. Refermez l'onglet, et motif comme texte disparaissent de la machine. Concrètement, vous pouvez travailler sur des extraits authentiques sans violer la moindre consigne de la CNIL.

Cinq usages respectueux des données

  • Anonymisez quand c'est possible. Remplacez les vrais noms par des libellés bidons pour la mise au point initiale, puis validez une dernière fois sur un échantillon réel limité.
  • Évitez la saisie tactile hasardeuse. Un motif maladroit sur un fichier de paie complète est vite arrivé : vérifiez d'abord sur trois lignes, pas sur la liste entière.
  • Fermez l'onglet après usage. Aucune donnée n'est conservée, mais le geste évite qu'un collégue regarde par-dessus l'épaule.
  • Pas de copie automatique. L'outil ne retient rien, mais le presse-papier, lui, garde votre dernier texte : videz-le après la session.
  • Pour les données sensibles, restez local. C'est l'argument de conception : un outil de debug ne devrait jamais être un collecteur.

Tous les métiers de bureau ne sont pas développeurs, mais tous manipulent des textes : un extrait de listing fournisseur, une liste de factures copiée d'un tableur, un courrier administratif dont il faut isoler les numéros de dossier. L'expression régulière est l'outil de prédiction pour ce genre d'extraction ; encore faut-il pouvoir la tester sans ouvrir un éditeur de code.

Ce testeur s'adresse donc aussi à ceux qui ne programment pas. Vous collez votre texte, vous décrivez le motif pas à pas, et le surlignage vous montre en direct ce qui sera capturé. Aucune compétence préalable n'est exigée : l'usage le plus courant reste l'extraction de références, de dates et de montants.

Cinq extractions utiles au bureau

  • Le code postal français : cinq chiffres d'affilée, facile à repérer pour trier une liste d'adresses par zone.
  • Le numéro SIRET : quatorze chiffres, pratique pour vérifier qu'un fournisseur est bien référencé.
  • Les dates en JJ/MM/AAAA : repérables d'un coup d'œil pour retrouver l'échéance d'un document.
  • Les montants avec deux décimales : utiles pour recouper une facture avec un relevé.
  • Les objets de formulaire type « Dossier n° 2026-... » : un motif simple isole les numéros de suivi.
