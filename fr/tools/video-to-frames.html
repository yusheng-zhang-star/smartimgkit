Comment extraire des images d'une vidéo

Guide détaillé pas à pas

Importer la vidéo

Glissez-déposez votre fichier vidéo dans la zone, ou choisissez-le depuis vos dossiers. Les formats MP4, MOV, WebM, AVI et MKV sont pris en charge.

Choisir le mode et le format

En mode intervalle, une photo est capturée toutes les N secondes. En mode nombre total, l'outil répartit équitablement les prélèvements sur toute la durée. Optez pour le JPG pour alléger les fichiers, ou le PNG pour préserver la qualité.

Lancer l'extraction

Appuyez sur Extraire. La première utilisation charge le moteur d'environ vingt-cinq mégaoctets ; ensuite, les traitements sont rapides, même sur une vidéo longue.

Télécharger

Si plusieurs images sont générées, elles sont regroupées dans une archive ZIP. Une seule image peut être enregistrée directement.
