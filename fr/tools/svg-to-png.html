Guide détaillé

Charger ou coller le SVG

Glissez un fichier .svg dans la zone de dépôt, ou basculez sur l'onglet « Coller le code SVG » pour coller le balisage brut. Pratique quand le SVG vient de Figma, de Sketch ou d'Illustrator : copiez le vecteur, collez-le, et la vignette apparaît aussitôt.

Choisir le format de sortie

Trois formats selon l'usage :

  • PNG : compression sans perte et transparence. Le choix par défaut pour les interfaces, logos et icônes.
  • JPG : fichier plus léger mais fond opaque. À réserver aux visuels denses sans zone transparente.
  • WebP : le meilleur compromis poids/qualité pour le web.

Régler le facteur d'échelle

Le facteur d'échelle pilote la résolution finale :

  • 1x : dimensions identiques au viewBox du SVG
  • 2x : double résolution — indispensable pour les écrans Retina (ressources @2x)
  • 3x : triple résolution pour les dalles haute densité
  • 4x : quadruple résolution pour l'impression

Un SVG étant vectoriel, l'agrandissement ne dégrade rien : un logo de 100×100 passe à 400×400 net à l'échelle 4x.

Télécharger le rendu

Cliquez sur Télécharger PNG pour enregistrer l'image rastérisée. Le fichier est généré intégralement dans votre navigateur, sans envoi vers un serveur.

Cas d'usage concrets

  • Designers : exporter une icône Figma en PNG @2x pour une application iOS ou Android
  • Intégrateurs web : figer un SVG inline en image statique pour une balise <img> ou un background-image
  • Impression : convertir un logo en PNG haute résolution pour cartes de visite et plaquettes
  • Présentations : transformer un graphique SVG en PNG pour PowerPoint ou Keynote
  • LinkedIn : préparer une illustration vectorielle en PNG pour un post ou une bannière

Conseils de pro

  • Pour des ressources mobiles nettes, gardez l'échelle 2x et la sortie PNG
  • Un SVG avec transparence doit sortir en PNG — le JPG remplirait le fond
  • WebP à 2x donne le fichier le plus léger pour une qualité équivalente
  • Les éléments <text> varient selon les navigateurs : convertissez le texte en tracés en amont
  • Pour l'impression, montez à 4x pour garder les détails fins
  • Coller le code évite d'enregistrer un fichier temporaire pour un essai rapide

Limites à connaître

Le rendu dépend du moteur SVG du navigateur : les filtres exotiques ou les polices non intégrées peuvent différer de votre outil de design. Les fichiers de plusieurs dizaines de Mo ralentissent l'aperçu — simplifiez le vecteur si besoin.
