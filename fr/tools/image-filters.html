Guide détaillé

Étape 1 : téléversez votre image

Cliquez sur la zone de dépôt ou glissez-y un fichier (JPG, PNG, WebP, GIF, BMP). L’image s’ouvre aussitôt dans le navigateur — rien ne part sur un serveur.

Étape 2 : appliquez un filtre prêt à l’emploi

Un clic sur l’un des quinze filtres suffit : Aucun, Niveaux de gris, Sépia, Inverser, Flou, Vintage, Froid, Chaud, Vibrant, Polaroid, Repoussage, Netteté, Teinte, Saturation. Le rendu est non destructif — changez de filtre ou réinitialisez quand vous voulez.

Étape 3 : affinez aux curseurs

Chaque curseur pilote un réglage précis :

  • Luminosité (0-300 %) : assombrit ou éclaircit l’ensemble
  • Contraste (0-300 %) : durcit ou adoucit l’écart entre les tons
  • Saturation (0-300 %) : dose l’intensité des couleurs (0 % = niveaux de gris)
  • Flou (0-20 px) : adoucit les détails pour un rendu onirique
  • Teinte (0-360°) : fait tourner toutes les couleurs sur la roue chromatique
  • Opacité (0-100 %) : règle la transparence générale

Étape 4 : téléchargez

Sélectionnez le format de sortie (PNG pour la qualité, JPG pour un fichier léger, WebP pour la compression moderne), cliquez sur Télécharger : l’image filtrée s’enregistre directement sur votre appareil.

Cas d’usage les plus fréquents

  • Annonces Leboncoin — un filtre Vibrant léger rend un objet plus attirant sans le dénaturer
  • Fils Instagram et Facebook — Vintage ou Polaroid pour une ambiance cohérente sur plusieurs publications
  • Portraits LinkedIn — +5 à +10 % de luminosité et +10 % de saturation pour un teint naturel
  • Illustrations de blog — Niveaux de gris + contraste pour un rendu éditorial sobre
  • Ambiances créatives — Flou + Saturation pour un effet pictural

Conseils de pro

  • Appliquez d’abord un filtre, puis corrigez aux curseurs : les deux se combinent en une seule passe
  • Le filtre Chaud flatte les tons de peau ; le filtre Vintage suivi d’une baisse de saturation imite l’argentique
  • Un léger flou (2-3 px) sur une photo de fond met le sujet en valeur
  • Enregistrez en PNG pour garder la qualité maximale, en JPG au-delà de 90 % pour alléger
  • Les couleurs à l’écran varient selon l’écran et le visionneur : jugez toujours sur l’appareil de destination
