Guide d'utilisation détaillé

Étape 1 : importer votre image

Cliquez sur la zone d'import ou glissez-déposez une image. Formats pris en charge : JPG, PNG, WebP. L'image se charge instantanément — rien n'est envoyé vers un serveur.

Étape 2 : choisir le format papier

Sélectionnez parmi les préréglages d'impression courants :

  • A4 (210×297mm) : Standard international, le plus répandu en France et en Europe
  • Letter (8.5×11") : Standard nord-américain, rare en France
  • A5 (148×210mm) : Moitié d'A4, pour les brochures et petits flyers
  • 10×15cm : Format photo standard pour les tirages papier
  • 13×18cm : Tirage photo plus grand, courant pour les cadres
  • Carte de visite (85×55mm) : Standard français et européen
  • Personnalisé : Saisissez n'importe quelle largeur et hauteur en pouces

Étape 3 : régler le DPI (points par pouce)

Le DPI détermine la qualité d'impression :

  • 72 DPI : Résolution écran, déconseillé pour l'impression
  • 150 DPI : Acceptable pour les très grands formats vus de loin
  • 300 DPI : Standard pour les tirages photo de haute qualité (recommandé)
  • 600 DPI : Impression professionnelle, fichiers très volumineux

Règle générale : Pour les tirages photo, utilisez toujours 300 DPI. Pour les grands banners vus de plus de 3 mètres, 150 DPI suffisent.

Étape 4 : télécharger

Cliquez sur Télécharger pour enregistrer votre image prête à imprimer. Le PNG est recommandé pour une qualité maximale ; le JPG à qualité 92+ est aussi acceptable pour les photos.

Cas d'usage recommandés

  • Tirages photo : Utilisez A4 ou 10×15cm à 300 DPI → JPG
  • Cartes de visite : Utilisez le préréglage Carte de visite à 300 DPI → PNG
  • Affiches/bâches : Taille personnalisée à 150 DPI → PNG
  • Documents : Utilisez A4 à 300 DPI → JPG
  • Tirage d'art : Utilisez A4/A5 à 600 DPI → PNG (qualité maximale)

Astuces de pro

  • Pour les tirages photo chez un labo, exportez toujours en 300 DPI dans l'espace colorimétrique sRGB
  • A4 à 300 DPI = 2480×3508 pixels — assurez-vous que votre image source fait au moins cette taille
  • Si votre image source est plus petite que la taille cible en 300 DPI, le résultat sera agrandi (perte de qualité) — utilisez d'abord notre outil d'agrandissement
  • Pour l'impression jet d'encre à domicile, 300 DPI est plus que suffisant — 150 DPI paraît quasiment identique
  • Enregistrez en JPG avec qualité 92-95 pour les tirages ; n'utilisez le PNG que si vous devez préserver du texte net ou des dessins au trait

Cartes de visite, flyers et documents administratifs : le standard français

En France, les documents suivent le standard ISO 216 : A4 (210×297 mm), A5 (148×210 mm), A6 (105×148 mm). Contrairement aux États-Unis, on n'utilise pas le format Letter pour les documents courants. Quand on prépare une image pour l'imprimerie, il faut donc viser le format A4 ou un format dérivé, pas le format nord-américain.
