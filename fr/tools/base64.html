📋 Encodeur Base64

Convertissez des images en Data URLs Base64 pour les intégrer directement dans votre HTML, CSS et JavaScript. Ou décodez une chaîne Base64 pour retrouver l'image.

🖼️ Essayer avec une image d'exemple

Comment Utiliser

1

Choisir la direction

Basculez entre Encodage (image→texte) ou Décodage (texte→image).

2

Importer

Importez une image ou collez une chaîne Base64.

3

Obtenir le résultat

Copiez la sortie ou téléchargez-la directement.

Guide d'utilisation détaillé

Mode 1 : Image → Base64 (Encodage)

Convertissez n'importe quelle image en Data URL Base64 pour l'intégrer directement dans votre code.

Basculez entre les modes Encodage et Décodage à l'aide des onglets en haut
  • Importez une image (JPG, PNG, WebP, GIF, BMP)
  • Cliquez sur « Encoder en Base64 »
  • La Data URL complète apparaît dans la zone de texte (format : data:image/png;base64,...)
  • Cliquez sur « Copier » pour copier dans le presse-papiers, ou sur « Télécharger en .txt » pour enregistrer
Quand l'utiliser : Intégrez de petites icônes directement dans le HTML/CSS pour éliminer les requêtes HTTP. Idéal pour les signatures d'email, les démos mono-fichier et les images de fond CSS.

Mode 2 : Base64 → Image (Décodage)

Convertissez une chaîne Base64 en une image consultable et téléchargeable.

  • Basculez vers l'onglet « Base64 → Image »
  • Collez une chaîne Base64 ou une Data URL complète dans la zone de texte
  • Cliquez sur « Décoder en image »
  • L'image décodée apparaît ci-dessous — cliquez sur « Télécharger l'image » pour enregistrer
Remarque : Si vous collez une chaîne Base64 brute sans le préfixe data:image/..., l'outil détecte automatiquement et ajoute l'en-tête approprié.

Cas d'usage recommandés

  • Images HTML en ligne — Intégrez de petites icônes et logos directement dans le HTML sans fichiers externes
  • Fonds CSS — Utilisez Base64 dans background-image: url() pour des feuilles de style autonomes
  • Signatures d'email — Assurez-vous que les images s'affichent correctement dans les clients de messagerie
  • Démos mono-fichier — Créez des fichiers HTML autonomes avec des images intégrées
  • Tests d'API — Inspectez et décodez les données d'image Base64 des réponses d'API

Astuces de pro

  • Base64 augmente la taille du fichier d'environ 33 % — ne l'utilisez que pour les petites images (<50 Ko idéalement)
  • Les Data URLs fonctionnent dans tous les navigateurs modernes et la plupart des clients de messagerie
  • Pour le CSS, utilisez background-image: url('data:image/png;base64,...')
  • Pour le HTML, utilisez <img src="data:image/png;base64,...">
  • Les très grandes images (>2 Mo) produiront des chaînes extrêmement longues qui peuvent ralentir le rendu de la page
