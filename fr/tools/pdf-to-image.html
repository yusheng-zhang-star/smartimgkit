Detailed User Guide

Step 1: Upload PDF

Click the upload area and select a PDF file.

Step 2: Choose Page Range

Select "All pages" or specify a range like "1-5".

Step 3: Choose Output Format

Select JPG, PNG, or WebP.

Step 4: Set Resolution

Choose 72 DPI (screen) to 300 DPI (print quality).

Step 5: Convert

Click "Convert to Images". Each page is rendered to an image.

Step 6: Download

Click "Download All ZIP" to get all pages.

Best Settings by Use Case

  • Social media — JPG, 150 DPI
  • Print — PNG, 300 DPI
  • OCR — PNG, 300 DPI
