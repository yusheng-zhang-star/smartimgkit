Ce que fait réellement l’encodeur

Transformer les caractères spéciaux en entités

Encoder, c’est remplacer les caractères que le HTML réserve à sa propre syntaxe par leur équivalent en entité : le chevron ouvrant devient <, le fermant >, et l’esperluette &. Le navigateur affiche alors le texte tel quel au lieu de l’interpréter comme du code.

Trois caractères seulement, et c’est voulu

Cet encodeur s’appuie sur la conversion native du navigateur pour les nœuds de texte, qui échappe &, < et > — rien de plus. Les guillemets ne sont pas convertis car ils ne posent problème qu’à l’intérieur d’un attribut. Si vous destinez le résultat à un attribut HTML, échappez-les à part.

Le décodeur comprend toutes les entités

Dans l’autre sens, il reconnaît aussi bien les entités nommées (&copy;, &eacute;) que les numériques (&#169;, &#233;) — pratique pour décoder des extraits venus d’un autre CMS ou d’exportations anciennes, quelle que soit la table utilisée.

Nos usages de tous les jours

Publier un extrait de code dans un article de blog sans que le navigateur ne l’exécute, transmettre par e-mail un gabarit HTML que le client de messagerie casserait sinon, ou documenter une balise dans un guide technique interne en gardant les chevrons visibles.

Les accents restent tels quels

Les lettres accentuées, les cédilles et l’ensemble des caractères Unicode ne sont pas touchés : ils apparaissent identiques dans le résultat. Seuls les trois caractères réservés changent — si votre publication exige des entités pour tout le monde, ce n’est pas l’outil qu’il vous faut, autant le savoir avant.

Deux boutons, zéro réglage

Aucune case à cocher, aucun mode : un bouton encode, l’autre décode. L’absence d’options supprime les erreurs de configuration et rend le résultat prévisible — ce que vous voyez est exactement ce que vous obtiendrez.

Confidentialité et limites

Tout se passe dans le navigateur avec les fonctions natives du DOM : le texte ne quitte jamais votre machine. Pas d’historique ni de limite pratique de taille, mais pour les textes très longs, copiez le résultat avant de recharger la page.
