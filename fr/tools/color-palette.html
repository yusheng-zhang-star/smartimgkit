Guide d'utilisation détaillé

Étape 1 : importer votre image

Importez n'importe quelle image JPG, PNG ou WebP. Cela fonctionne très bien avec des photos, des illustrations, des captures d'écran, ou toute image avec des couleurs intéressantes.

Importez une image et choisissez combien de couleurs dominantes extraire

Étape 2 : choisir le nombre de couleurs

Utilisez le curseur pour sélectionner combien de couleurs extraire (3 à 12). Plus de couleurs donnent une palette plus riche ; moins de couleurs donnent un schéma plus ciblé et minimaliste.

  • 3-4 couleurs — Idéal pour un branding simple et des designs minimalistes
  • 5-6 couleurs — Palette équilibrée pour la plupart des projets web et d'interface
  • 8-12 couleurs — Palette complète pour les designs complexes et les illustrations

Étape 3 : extraire et utiliser

Cliquez sur « Extraire les couleurs » pour analyser l'image. L'outil affiche :

  • Des nuanciers avec les valeurs HEX et RGB
  • Des variables CSS prêtes à l'emploi que vous pouvez copier directement dans votre feuille de style

Cliquez sur n'importe quel nuancier pour copier instantanément son code HEX dans votre presse-papiers.

Astuce : La première couleur est généralement la plus dominante. Utilisez-la comme couleur de marque principale, et les autres comme accents et neutres.

Cas d'usage recommandés

  • Inspiration de couleurs de marque — Extrayez les couleurs d'un moodboard ou d'une image de référence
  • Thème de site web — Harmonisez la palette de votre site avec une photographie clé ou une image produit
  • Design d'interface — Générez des schémas de couleurs accessibles pour les applications et les tableaux de bord
  • Art et illustration — Construisez des palettes harmonieuses à partir de photos de nature ou d'œuvres d'art

Astuces de pro

  • Les images avec des couleurs fortes et distinctes donnent les meilleures palettes
  • Utilisez la sortie CSS directement dans le :root de votre projet pour un thème cohérent
  • Essayez d'extraire depuis plusieurs images et de combiner les palettes pour des combinaisons uniques
  • L'algorithme trouve les couleurs visuellement dominantes, pas seulement les plus fréquentes statistiquement
