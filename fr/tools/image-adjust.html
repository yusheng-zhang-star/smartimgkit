🎚️ Ajuster l’image

Réglez la luminosité, le contraste et la saturation d’une photo, puis comparez le résultat à l’original. Tout se passe dans votre navigateur.

Comment utiliser

1

Téléverser

Choisissez une photo depuis votre appareil ou essayez avec l’image d’exemple.

2

Ajuster

Utilisez les trois curseurs pour régler luminosité, contraste et saturation.

3

Télécharger

Cliquez sur Appliquer pour générer le rendu, puis sur Télécharger pour enregistrer.

Guide détaillé

Étape 1 : téléversez votre image

Cliquez sur la zone de dépôt ou glissez-déposez un fichier image (JPG, PNG ou WebP). L’originale s’affiche dans la zone d’aperçu et vous pouvez commencer à régler tout de suite.

Étape 2 : réglez luminosité, contraste et saturation

Trois curseurs suffisent pour affiner le rendu :

  • Luminosité (0 %–200 %) — assombrit ou éclaircit l’image ; 100 % correspond à la luminosité d’origine.
  • Contraste (0 %–200 %) — durcit ou adoucit l’écart entre les tons ; 100 % correspond au contraste d’origine.
  • Saturation (0 %–300 %) — désature (0 % = noir et blanc) ou ravive les couleurs ; 100 % correspond à la saturation d’origine.
Astuce : les curseurs ne mettent à jour que les pourcentages ; le rendu de l’image se génère quand vous cliquez sur « Appliquer les réglages ». Ajustez les trois valeurs, appliquez, puis jugez à l’œil.

Étape 3 : appliquez et téléchargez

Cliquez sur « Appliquer les réglages » pour générer le rendu final avec les trois réglages combinés, puis sur « Télécharger » pour enregistrer l’image ajustée en JPG.

Cas d’usage les plus fréquents

  • Rattraper une photo sous-exposée — augmentez la luminosité pour retrouver le détail dans les zones sombres
  • Raviver les couleurs d’une annonce — un coup de saturation sur les photos d’un article Leboncoin les rend plus attirantes
  • Donner du relief à un portrait LinkedIn — un léger gain de contraste suffit, sans excès
  • Obtenir un rendu noir et blanc — descente de saturation à 0 %

Conseils de pro

  • Sur un portrait, ne dépassez pas 150 % de luminosité : les tons de peau deviennent artificiels
  • Combinez +20 % de contraste et +15 % de saturation pour un rendu « vif » immédiat
  • Si l’image semble plate après une baisse de contraste, remontez légèrement la saturation
  • Pour l’impression, restez à 110 % de luminosité maximum : l’écran (RVB) envoie plus de lumière qu’une feuille imprimée
