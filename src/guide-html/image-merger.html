Detailed User Guide

Step 1: Upload Your Images

Click the upload area or drag multiple images onto it. You can select several files at once from your file browser. All common formats (JPG, PNG, WebP) are supported. The images appear as thumbnails in the sidebar where you can see their filenames and dimensions.

Step 2: Pick a Layout Mode

Choose from three layout modes:

  • Grid Collage: Automatically arranges images in a grid. Choose the number of columns or let it auto-calculate based on image count. Great for photo collages and comparison grids.
  • Horizontal Merge: Places images side by side from left to right. Ideal for before/after comparisons, panoramic stitching, or horizontal banners.
  • Vertical Merge: Stacks images top to bottom. Perfect for long screenshots, vertical stories, or step-by-step tutorials.

Step 3: Reorder & Customize

Drag any image thumbnail in the sidebar to rearrange the order. Use the controls to fine-tune your layout:

  • Spacing: Gap between images (0-40px)
  • Border Radius: Round the corners of each image (0-30px)
  • Background: Set the color that fills the gaps and padding
  • Format: Choose PNG (lossless), JPG (smaller), or WebP (modern)
Tip: The preview updates in real-time as you change settings. What you see is what you get.

Step 4: Merge & Download

When you're happy with the layout, click "Merge & Download" to generate the final image. The file downloads immediately to your device. No watermarks, no quality loss, no server uploads.

Best Use Cases

  • Photo collages — Combine vacation photos, family pictures, or event highlights into a single shareable image
  • Before & after — Place two photos side by side to show edits, renovations, or transformations
  • Social media grids — Create 3x3 Instagram grid posts from 9 separate images
  • Comparison charts — Merge product photos horizontally for visual comparison
  • Step-by-step tutorials — Stack screenshots vertically for how-to guides
  • Story highlights — Combine multiple story-sized images into one tall image

Pro Tips

  • For the cleanest grid collage, use images with the same dimensions — the tool will resize them to fit evenly
  • Set spacing to 0 and radius to 0 for a seamless panoramic merge
  • Use a dark background color (#000000 or #1a1a2e) for a sleek collage look
  • For before/after comparisons, use Horizontal mode with two images and 2-4px spacing
  • PNG preserves transparency — if any input image has a transparent background, choose PNG output
  • Add more images anytime with the "Add More Images" button at the bottom of the image list
