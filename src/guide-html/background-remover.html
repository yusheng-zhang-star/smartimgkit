How the AI Background Remover Works

This tool uses @imgly/background-removal v1.7.0, an open-source AI model that runs entirely in your web browser using WebAssembly (WASM) and ONNX Runtime. Here's what happens behind the scenes:

  • Model Loading: On first use, the AI model (40-170MB depending on quality setting) downloads to your browser's cache. This takes 10-60 seconds depending on your connection and selected model. The model is then cached for instant future use.
  • Image Preprocessing: Your image is resized to the model's input dimensions while preserving aspect ratio, then normalized for the neural network.
  • Semantic Segmentation: The AI model performs pixel-level classification, identifying which pixels belong to the foreground (subject) and which belong to the background. It uses a deep neural network trained on millions of images.
  • Alpha Mask Generation: The model outputs an alpha mask (transparency map) where each pixel gets a value from 0 (fully transparent) to 255 (fully opaque).
  • Edge Refinement: The alpha mask is refined using guided filtering to produce clean, natural edges — especially important for hair, fur, and semi-transparent areas.
  • Composition: The original image is composited onto a transparent canvas using the generated alpha mask, producing the final transparent PNG.
Privacy Note: Every step happens on your device. No image data is ever transmitted to a server. This is the most private way to use AI background removal.
