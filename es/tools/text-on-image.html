Guía Detallada

Paso 1: Subir tu Imagen

Haz clic en el área de carga o arrastra y suelta un archivo de imagen. Los formatos admitidos incluyen JPG, PNG y WebP. La imagen se carga al instante y aparece en el lienzo de vista previa. Tu imagen permanece en tu dispositivo — nada se sube a ningún servidor.

Paso 2: Introducir tu Texto

Escribe tu texto en el campo "Texto". Puedes escribir cualquier cosa — una palabra, una frase o incluso varias líneas. Luego personaliza la apariencia:

  • Font Family: Choose from 10 curated fonts — from professional (Inter, Roboto) to decorative (Pacifico, Permanent Marker)
  • Font Size: Adjust from 10px to 200px. The preview updates in real-time
  • Font Weight: Switch between Normal and Bold
  • Text Color: Use the color picker to choose any color for your text

Paso 3: Posicionar y Estilizar

Coloca tu texto exactamente donde quieras:

  • Drag on canvas: Click and drag the text directly on the preview to position it precisely
  • Quick Position: Use the 9-position grid (top-left, center, bottom-right, etc.) for fast placement
  • Outline: Add a colored outline around your text for readability. Set the color and width (0-10px)
  • Shadow: Add a shadow blur to make text pop off the image (0-30px)
  • Opacity: Make text semi-transparent (10-100%) for watermarks
  • Rotation: Rotate text from -180° to 180° for creative effects

Paso 4: Descargar

Cuando estés satisfecho con el resultado, elige tu formato de salida y haz clic en "Descargar". El archivo se guarda inmediatamente en tu dispositivo. Sin marcas de agua, sin pérdida de calidad.

Mejores Casos de Uso

  • Memes — Add bold, outlined text to photos for shareable memes
  • Inspirational quotes — Overlay beautiful text on scenic photos
  • Watermarks — Add semi-transparent text watermarks to protect your images
  • Social media graphics — Create eye-catching text overlays for Instagram, Twitter, etc.
  • Presentations — Add labels and captions to images for slides
  • Event graphics — Create "Coming Soon", "Save the Date", or announcement images

Consejos Profesionales

  • For maximum readability on any background, use white text with a black outline — the classic meme style
  • For subtle watermarks, set opacity to 30-50% and use a semi-transparent color
  • Pacifico and Dancing Script are great for elegant, script-style text
  • Bebas Neue and Oswald work well for bold, impactful headlines
  • Press Start 2P is perfect for retro/pixel art style
  • Use rotation at 15-30° for dynamic, energetic text on action photos
