📋 Codificador Base64

Convierte imágenes a Base64 data URLs y viceversa.

🖼️ Probar con imagen de ejemplo

Cómo Usar

1

Elegir Dirección

Cambia entre Codificar (imagen→texto) o Decodificar (texto→imagen).

2

Entrada

Sube una imagen o pega una cadena Base64.

3

Obtener Resultado

Copia el resultado o descárgalo directamente.

Guía Detallada

Modo 1: Imagen → Base64 (Codificar)

Convierte cualquier imagen a una URL de datos Base64 para incrustar directamente en código.

Alterna entre los modos Codificar y Decodificar con las pestañas superiores
  • Sube una imagen (JPG, PNG, WebP, GIF o BMP)
  • Pulsa «Codificar a Base64»
  • La URL de datos completa aparece en el cuadro de texto (formato data:image/png;base64,...)
  • Pulsa «Copiar» para llevarla al portapapeles o «Descargar como .txt» para guardarla
Cuándo usarlo: incrusta iconos pequeños directamente en HTML o CSS para eliminar peticiones HTTP. Perfecto para firmas de correo, demos de un solo archivo e imágenes de fondo en CSS.

Modo 2: Base64 → Imagen (Decodificar)

Convierte una cadena Base64 de vuelta a una imagen visible y descargable.

  • Cambia a la pestaña «Base64 → Imagen»
  • Pega una cadena Base64 o una URL de datos completa en el cuadro de texto
  • Pulsa «Decodificar a imagen»
  • La imagen decodificada aparece debajo: pulsa «Descargar imagen» para guardarla
Nota: si pegas una cadena Base64 sin el prefijo data:image/..., la herramienta lo detecta y añade la cabecera correcta automáticamente.

Mejores Casos de Uso

  • Imágenes incrustadas en HTML — mete iconos y logotipos pequeños directamente en el HTML, sin ficheros externos
  • Fondos CSS — usa Base64 en background-image: url() para hojas de estilo autocontenidas
  • Firmas de correo — asegura que las imágenes se vean bien en los clientes de correo
  • Demos de un solo archivo — crea HTML autónomos con las imágenes incrustadas
  • Pruebas de API — inspecciona y decodifica imágenes Base64 dentro de respuestas de API

Consejos Profesionales

  • Base64 aumenta el tamaño alrededor de un 33%: úsalo solo con imágenes pequeñas (idealmente por debajo de 50 KB)
  • Las URLs de datos funcionan en todos los navegadores modernos y en la mayoría de clientes de correo
  • En CSS, usa background-image: url('data:image/png;base64,...')
  • For HTML, use <img src="data:image/png;base64,...">
  • Las imágenes muy grandes (más de 2 MB) generan cadenas larguísimas que pueden ralentizar la renderización de la página
