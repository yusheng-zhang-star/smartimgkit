Generador de Iconos ICO

Convierte cualquier imagen a un archivo ICO multi-tamaño o paquete completo de iconos. Elige tamaños, algoritmo de escalado, esquinas redondeadas y color de fondo.

Tamaños de Icono

Opciones

Máscara aplicada a cada tamaño. Pon 0 para cuadrado. Estilo iOS ≈22% del tamaño del icono.

Descargar

Vista Previa

Cada vista muestra el resultado renderizado en ese tamaño (1× y 4× ampliado para inspección).

Cómo Usar

1

Subir Imagen

Haz clic para elegir PNG, JPG, SVG o WebP.

2

Elegir Tamaños y Opciones

Marca los tamaños deseados y ajusta el escalado.

3

Descargar

Descarga ICO individual o ZIP con todos los PNGs.

Guía Detallada

Paso 1: Sube una Imagen Cuadrada

Arrastra y suelta una imagen cuadrada. PNG con transparencia funciona mejor.

Paso 2: Elige los Tamaños

Activa los chips de tamaño. El archivo ICO contendrá exactamente los tamaños seleccionados.

Paso 3: Ajusta el Renderizado

Configura el escalado, esquinas redondeadas, fondo y relleno.

Paso 4: Vista Previa

Cada tamaño seleccionado se muestra en la cuadrícula de vista previa.

Paso 5: Descargar

Haz clic en "Descargar ICO" para un solo archivo, o en "Descargar ZIP" para cada tamaño como PNG.

Formato de Archivo ICO

ICO es un formato contenedor que puede contener múltiples tamaños de imagen en un solo archivo. Cada entrada es una imagen completa (el ICO moderno usa PNG).
