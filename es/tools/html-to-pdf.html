Convertir HTML a PDF: guarda el contenido en un documento

Con Convertir HTML a PDF pasas una página o un fragmento de código a un documento PDF ordenado con el texto del contenido. Sube el archivo .html o pega el código directamente; la conversión ocurre en tu navegador, sin subir nada.

⚡

Archivar artículos y boletines

La web cambia y lo que hoy lees mañana puede desaparecer. Guarda el HTML de un artículo o una newsletter y conviértelo en un PDF ordenado que forma parte de tu archivo de consulta.
