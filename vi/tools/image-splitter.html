Detailed User Guide

Step 1: Upload Your Image

Click the dropzone or drag and drop an image file (JPG, PNG, or WebP). The original image will be displayed and you can preview the split result immediately.

Step 2: Choose Grid Size

Select the grid layout:

  • 2×2 — Split into 4 equal pieces. Great for Instagram carousel posts.
  • 3×3 — Split into 9 pieces. Perfect for a 3×3 grid feed.
  • 1×2 / 2×1 — Split horizontally or vertically into 2 pieces.
  • 1×3 / 3×1 — Split into 3 pieces for panoramic posts.
Tip: For Instagram grid feed, use 3×3 and post the pieces in order from left to right, top to bottom.

Step 3: Download Pieces

After splitting, you can download each piece individually, or click "Download All (ZIP)" to get all pieces in one ZIP file.

Best Use Cases

  • Instagram grid feed — Create a giant grid by posting split pieces in order
  • Carousel posts — Split one image into multiple slides
  • Print layout — Split a large poster into printable A4 pieces
  • Web design — Break a hero image into lazy-loaded pieces
