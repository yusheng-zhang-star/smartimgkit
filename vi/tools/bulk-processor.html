Detailed User Guide

Step 1: Upload Multiple Images

Drag and drop a folder of images or select many files at once.

Step 2: Configure Processing Options

Click "Processing Options" to expand settings. You can choose resize mode, output format, quality, and watermark text.

Step 3: Process All

Click "Process All". A progress bar shows which file is being processed.

Step 4: Download ZIP

When processing finishes, click "Download ZIP" to get all processed images in one archive.
