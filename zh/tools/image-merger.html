详细使用指南

第一步：上传多张图片

点击虚线框或直接把文件拖进去，文件浏览器里可以按住 Ctrl（Mac 上是 Command）一次选中多张。支持 JPG、PNG、WebP 等常见格式，上传后缩略图会出现在左侧列表，并显示文件名和像素尺寸。图片完全没有离开你的设备——工具只是用浏览器的文件读取接口把它们读进内存。

第二步：选一种合并布局

三种布局对应三种用途：

  • 网格拼图：图片按行列自动排列，列数可选 2–5 或自动计算。适合九宫格晒图、多角度商品图、效果对比墙。
  • 横向并排：从左到右依次摆放，所有图片统一高度。适合前后对比、横幅图、全景拼接。
  • 纵向拼接：从上到下堆叠，所有图片统一宽度。适合长截图、步骤教程、聊天记录。

第三步：调细节和顺序

左侧缩略图可以直接拖动排序，拖完预览立即更新。下面几个参数决定成图效果：

  • 间距：0–40px。设 0 得到无缝长图，8–12px 适合卡片式拼贴。
  • 圆角：0–30px。给每张图单独加圆角，配合彩色背景更好看。
  • 背景色：填充间距和边框区域。白色最通用，深色适合做暗色拼图。
  • 输出格式：PNG 无损、支持透明；JPG 体积小；WebP 体积最小且画质好。
提示：所有调整都是实时的，看到什么就导出什么，不用反复试。

第四步：合并并下载

满意后点「合并并下载」，浏览器会直接生成成品图片并保存到本地下载目录。没有水印、没有二次压缩、也不会先上传到任何服务器中转。

常见使用场景

  • 电商详情页：把主图和细节图横向排开，或 2×2 网格展示不同颜色
  • 前后对比：修图、装修、健身记录，两张并排最有说服力
  • 九宫格发布：9 张照片按 3 列拼成一张，发朋友圈或小红书
  • 教程长图：手机截图纵向堆叠，间距设 0 就是一张干净的步骤长图
  • 比价与选款：同类商品横向排列，一眼看出差异

出图小技巧

  • 网格模式下，尺寸接近的图片拼出来最整齐，工具会把它们缩放填进等大的格子
  • 做无缝全景图：间距设 0、圆角设 0、背景色无所谓（不露出）
  • 做前后对比：横向模式 + 两张图 + 2–4px 间距，视觉上最干净
  • 原图有透明背景时务必选 PNG 输出，JPG 会把透明区域填成白色
  • 单次建议控制在 20 张以内，图太多时浏览器预览会变慢
  • 随时可以点「添加更多图片」继续加图，不用重新开始
