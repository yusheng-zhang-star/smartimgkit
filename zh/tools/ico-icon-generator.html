详细使用指南

第一步：上传正方形原图

拖入或点选一张正方形图片，带透明通道的 PNG 效果最好，后续缩放到小尺寸时边缘最干净。

第二步：勾选需要的尺寸

点开尺寸方格即可勾选或取消。最终 ICO 文件里只会打包你选中的那些尺寸，勾得越准文件越小。

第三步：调整渲染参数

缩放算法选高质量最稳妥；圆角按软件风格调整，底色可设透明或纯色，内边距用来给图标四周留白。

第四步：查看实时预览

右侧预览区会把每个选中尺寸都画出来，放大检查小字、轮廓和边缘是否发虚。

第五步：导出成品

点「下载 ICO 文件」拿到单个图标文件；点「下载整套图标包」则得到每个尺寸的 PNG 加一个 ICO，适合直接放进项目。

ICO 文件格式说明

ICO 是一种容器格式，一个文件里可以同时装下多个尺寸的图像。现代 ICO 内部每一条都是完整的 PNG 图像，Windows 会按显示场景自动挑最合适的尺寸。

个人开发者打包 Windows 软件时，图标一次做全省得返工

国内很多独立开发者、外包团队和工作室都有过这种经历：软件功能写好了，打包给客户一看，桌面上的图标还是编译器默认的一片空白，或者大小只有一档，放到高分屏任务栏上糊成一团。传统做法是打开专业设计软件，反复导出十几种尺寸，再手动改安装包配置，折腾大半天。用这个 ICO 图标生成器，流程被压缩到几分钟：准备一张正方形原图，勾选需要的尺寸，一键导出整套图标，直接替换进项目目录就行。

整个过程在浏览器本地完成，原图不会上传到任何服务器。对小团队来说这一点很实际——图标里可能包含客户的商标、未发布的产品视觉，把这类素材传到在线转换网站总有点不放心，在这里处理完关掉页面，素材就从浏览器内存里清掉了。

给国内开发者的五条实操建议

  • Windows 安装包至少勾四档。任务栏常用 16 和 24 像素，桌面快捷方式用 48 像素，安装界面和开始菜单用 256 像素，缺哪一档，哪个位置的图标就发虚。
  • 原图尽量给 1024 像素以上。图标工具是往下缩放的，原图越大，缩到 16 像素时边缘越干净；拿手机截图直接当原图，小尺寸多半会锯齿。
  • 圆角按平台风格走。Windows 桌面图标不强制圆角，设成 0 最稳；如果你的软件同时要发安卓版，可以把圆角调到 22% 左右，一次出两套风格。
  • 导出整套图标包而不是单个 ICO。压缩包里每个尺寸都有独立 PNG，做安装包、写文档、发应用商店时都能直接取用，不用回头再来一遍。
  • 透明背景适合带图形标志的图标；纯色填充适合只有文字的图标。文字小图标在透明背景下边缘容易散，垫一层底色会清晰很多。

给国内电商和自媒体从业者的建议

  • 店铺头像用 512 像素 PNG 导出。淘宝、拼多多、京东后台都会自动再压缩，给够原始尺寸，压缩后边缘才不会发虚。
  • 关键信息放在正中间。公众号头像会被自动裁成圆形，店铺头像也常被加圆角边框，把品牌名称和图形标志居中，四周留出安全边距。
  • 小尺寸检查别跳过。把 16、32 像素两档勾上，放大预览看看店名还认得出吗；认不出就加大字号、简化图形，宁可少一个装饰元素。
  • 底色统一。店铺在不同平台用不同头像容易让顾客认不出，建议选一个固定品牌色做纯色填充，跨平台保持一致。
  • 整套图标包留档。每次改版图标后，把压缩包按日期存一份，以后做直播封面、短视频水印、快递面单贴纸时，直接从里面取对应尺寸。

学生、老师和上班族：把电脑文件夹和快捷方式换成自己的图标

不是只有做软件才需要 ICO。国内学生党和上班族的电脑桌面常年堆着几十上百个文件夹：课程资料、论文版本、报销票据、项目合同、简历附件，全靠系统默认的黄色文件夹图标排在一起，找东西全凭记忆点。把常用文件夹换成自定义图标，是花五分钟就能让电脑清爽一个档次的小改造，而这个工具就是干这件事最简单的办法。

Windows 系统允许给任意文件夹指定一个 ICO 文件作为图标：右键文件夹、属性、自定义、更改图标，选好之后，资源管理器里的这个文件夹立刻变成你自己的图案。配合本工具，你可以给「论文」文件夹放一支笔的图案，给「报销」文件夹放一张票据的图案，给「项目」文件夹放一个小房子的图案，桌面和文档区立刻井井有条。

给学生和上班族的实用建议

  • 做文件夹图标别用照片。照片缩到 32 像素什么都认不出，用简洁的单色图形或文字符号，小尺寸才清晰。
  • 底色设成纯色。文件夹图标在资源管理器里背景是浅的，透明图标在浅色模式下边缘容易融掉，垫一层品牌色或浅色底更醒目。
  • 圆角设 0。文件夹图标本来就是方的，加圆角反而显得奇怪；想要苹果风格圆角的话，那是给应用图标准备的。
  • 一次导出三档就够。文件夹图标在资源管理器里最大显示 48 像素左右，勾 32、48、256 三档，兼顾大图标视图和高分屏。
  • 整套留一份。做好的图标包按用途命名存档，以后重装系统、换电脑，直接拷过去就能恢复整套桌面布局。

老师和行政人员也适用：教研室老师把教学大纲、试卷模板、成绩单模板各自做成图标，学生交来的作业文件夹统一图案，打开教务目录时分类一目了然。公司行政同事给共享盘里的常用文件夹换图标，新员工入职找合同模板、报销流程、通讯录，不用再问来问去。

这类改造完全不碰系统文件，只是给文件夹挂一个图标引用，不喜欢随时可以改回来，没有任何风险。工具全程在浏览器本地运行，自己的证件照扫描件、合同截图这类敏感素材，不用上传到任何网站，处理完即关即走。对每天和大量文档打交道的人来说，这是典型的小投入、长期省事的电脑整理习惯。
