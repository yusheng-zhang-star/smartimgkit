Detailed User Guide

Step 1: Upload a Square Image

Drag and drop a square image. PNG with transparency works best.

Step 2: Pick Sizes

Toggle the size chips. The ICO file will contain exactly the selected sizes.

Step 3: Adjust Rendering

Configure scaling, rounded corners, background, and padding.

Step 4: Preview

Each selected size is rendered in the preview grid.

Step 5: Download

Click "Download ICO" for a single file, or "Download ZIP Pack" for every size as PNG.

ICO File Format

ICO is a container format that can hold multiple image sizes in one file. Each entry is a full image (modern ICO uses PNG).
