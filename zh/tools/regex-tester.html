使用方法

在"正则表达式"输入框写下模式，例如 \d+ 匹配一串数字。

2

按需勾选 g、i、m、s：全局、忽略大小写、多行、点号匹配换行。

4

查看结果

匹配在原文中高亮，下方列表给出每处匹配的位置与捕获组。

详细使用指南

输入即测，无需按钮

正则和测试文本两个输入框任意一个变化，结果就重新计算。调正则时最怕"改一下、跑一下"的往返——这里每次按键都能看到新的匹配范围，贪婪与懒惰量词的差别一改便知。

四个标志各管什么

g 让正则找出全部匹配而不是停在第一处；i 让字母匹配忽略大小写；m 让 ^ 和 $ 按行生效而不是只认整段开头结尾；s 让点号也能匹配换行符。写多行日志解析时 m 和 s 经常要一起开。

匹配列表包含哪些信息

除高亮外，每处匹配标注了起始下标和捕获组内容。写替换逻辑前先确认分组顺序，避免 $1、$2 张冠李戴。命名捕获组（?<名称>…）同样能正常解析。

这是 JavaScript 方言

工具用的是浏览器内置的 JavaScript 正则（ES2018+），支持前后查找与命名分组，但与 PCRE 有细节差异：例如 \p{…} Unicode 属性需要 u 标志、递归匹配不支持。给 PHP 或 Python 写正则时请以各自运行环境为准。

报错原样显示

模式不合法时，页面直接展示浏览器的原始错误信息，比如"缺少终止括号"。比起静默失败，你能立刻定位是哪个字符写错了。

隐私与边界

全部计算在本机浏览器完成，输入不会上传。工具只做匹配测试，不生成代码、不保存历史；超大文本（几十万行）渲染高亮会变慢，建议截取有代表性的片段测试。
