如何将 HEIC 转换为 JPEG：解决 iPhone 照片无法打开的问题

如果你的 iPhone 照片在 Windows、Android 或旧版应用中无法打开，它们很可能是 HEIC 格式。最快的解决办法：打开 SmartImgKit HEIC 转 JPEG，拖入文件，下载即可。无需上传，无需安装。本指南涵盖何时保留 HEIC、何时转换，以及真正重要的 3 个设置。

1. HEIC 是什么，Apple 为什么使用它？

HEIC 的全称是 High Efficiency Image Container（高效图像容器）。Apple 从 2017 年的 iOS 11 开始将其作为默认照片格式。卖点很简单：在视觉效果相同的情况下，HEIC 文件大小约为 JPEG 的一半。你那张本来会是 3MB JPEG 的 1200 万像素 iPhone 照片？转眼就变成了 1.5MB 的 HEIC。大多数人都会拍几千张照片，乘以这个数量，省下的存储空间相当可观。

顺便说一句，Apple 并没有大张旗鼓地宣传这个变化。大多数人只有在出问题时才发现 HEIC 的存在——文件上传失败、程序打不开，或者对方说"我看不到你发来的照片。"等到那时，你手机里已经躺了几百上千个 HEIC 文件，而你甚至都不知道它们不是普通的 JPEG。

说实话，这个格式本身并不差。它使用的是基于 HEVC（H.265）视频编解码器的高级压缩技术，比 1992 年那套老旧的 JPEG 压缩算法效率高得多（好吧，这话听起来理所当然）。问题不在技术本身——而在于世界其他地方还没跟上节奏。

2. 没人提醒过你的兼容性问题

麻烦就出在这里。Apple 设备处理 HEIC 毫无压力——Mac、iPhone、iPad，都没问题。大多数现代浏览器（Chrome、Firefox、Edge、Safari）也能显示 HEIC 图像，至少在较新的版本里可以。但一旦走出这个生态圈，各种问题就接踵而至。

旧版 Windows？黑屏或报错。很多支持上传照片的网站？"不支持的文件类型。"邮件客户端？取决于收件方使用的软件。某些图像编辑工具？不行。WordPress 或 Squarespace？通常也不接受。社交媒体平台处理方式各异——Instagram 接受 HEIC，但那些老论坛或商品展示网站呢？肯定不行。

我觉得遇到 HEIC 的麻烦归根结底就三种情况。一：把产品照片发给使用 Windows 或旧软件的客户。二：上传到非主流社交媒体的网站。三：用只接受 JPEG 或 PNG 的工具批量处理图像。第一种最尴尬——发了一堆"专业"照片，客户却根本打不开。

3. 如何从一开始就阻止 iPhone 保存为 HEIC

如果你已经厌倦了和 HEIC 打交道，可以把 iPhone 切回 JPEG。只需改一个设置。

进入 设置 → 相机 → 格式。你会看到两个选项："高效"（即 HEIC）和"兼容性最好"（即 JPEG）。点选"兼容性最好"，从此你的 iPhone 拍出的每张照片都是标准 JPEG。

不过代价是存储空间。JPEG 文件大约是 HEIC 的两倍大。如果你拍照很多，手机会更快被占满。在一部存了 10000 张照片的 128GB iPhone 上，差距大约多占用 15-20GB 存储空间。如果你本来空间就紧张，这就是个大问题。

你也可以保持 HEIC 为默认格式，但在分享或传输照片时让 iPhone 自动转换为 JPEG。在同一个 设置 → 相机 → 格式 菜单里，往下滚动找到"传输到 Mac 或 PC"。如果你想要真正的 HEIC 文件，把它从"自动"改为"保留原片"；如果你想在 AirDrop 或连接电脑时自动转换，就保持原样。

我的建议是：如果你只是偶尔拍拍照、偶尔发给别人，就切到"兼容性最好"。如果你拍照很多、存储空间又重要，就保留 HEIC，需要分享时再转换。接下来我就讲讲这种方法。

4. 最快的方法：在浏览器中将 HEIC 转换为 JPEG

对大多数人来说，转换 HEIC 文件意味着找个网站、上传照片、等待、再下载 JPEG。其中有些网站还不错。另一些则会给你转换后的图片打上水印、逼你注册账号，或者在三次"免费"转换后用付费墙扣住你的文件。

有一种更干净的做法。SmartImgKit HEIC 转换器完全在浏览器中运行——你的照片永远不会离开你的设备。没有服务器上传，无需创建账号，没有文件大小限制。拖入一个 HEIC 文件（或多个），它就能输出 JPEG 或 PNG。

分步操作

第 1 步：在任何现代浏览器中打开 smartimgkit.com/tools/heic-converter。桌面端和移动端均可使用。

第 2 步：把 HEIC 文件拖到上传区域，或点击浏览选择。可以一次拖入多个文件——不必一个个转换。

第 3 步：选择输出格式。JPEG 是默认选项，几乎适用于所有场景。如果需要透明背景或无损画质就选 PNG，但文件会更大。

第 4 步：按需调整质量滑块。默认值（85%）在文件大小和视觉质量之间是个不错的平衡。用于网站的产品照片，80-90% 足够。用于存档或打印，可以调到 95%。

第 5 步：点击转换。几秒钟后（取决于文件数量和你的设备），你会看到转换后图像的预览及其新文件大小。对比原始 HEIC 大小和 JPEG 大小——差距通常不大。

第 6 步：逐个下载文件，或一次性把它们打包成 ZIP 下载。

在性能不错的电脑上，转换一批 20 张照片大约需要 30 秒。在手机上可能要一分钟。不管怎样，这都比寻找并安装桌面软件、注册账号，或折腾 Apple 的导出选项要快。

为什么基于浏览器的转换在这里更合适

说实话，隐私是最大的好处。照片文件包含 EXIF 数据——位置、时间戳、设备信息。当你把 HEIC 文件上传到某个随机转换网站时，这些数据也跟着走了。基于浏览器的工具在本地处理一切，什么都不会离开你的设备。对个人照片来说这很重要；对包含客户信息或未发布产品图的商业照片来说，更是至关重要。

另外就是速度。没有上传等待，没有排队，没有"处理需要 5-10 分钟"。转换速度取决于浏览器的处理能力，对现代设备来说非常快。

5. 在 Mac 上转换 HEIC

如果你用的是 Mac，有内置选项，不需要额外软件。

使用"预览"应用

最简单的方法：双击 HEIC 文件在"预览"中打开，然后进入 文件 → 导出。从格式下拉菜单中选择 JPEG，选一个质量等级，保存即可。这样处理一个文件就好了。处理几张图片还行，处理几十张就太繁琐了。

使用"照片"应用

在"照片"应用中选中一张或多张 HEIC 照片。进入 文件 → 导出 → 导出 [数量] 张照片。在导出对话框中，把"种类"改为 JPEG，设置质量偏好，选择目标文件夹。这适用于批量处理，但对压缩设置的控制有限。

使用 Automator（用于大批量）

如果不想用第三方软件进行批量转换，可以设置一个 Automator 工作流。新建一个快速操作，设置为在访达中接收图像文件，添加一个"更改图像类型"操作并设为 JPEG，然后保存。之后你就可以右键点击任意 HEIC 文件（或选中多个），从访达菜单运行你的工作流。这是一次性设置，如果你经常要转换成堆的 iPhone 照片，能省下大量时间。

或者老实说？你可以跳过这些，直接用 基于浏览器的转换器。一次性转换我还是会用"预览"，因为它本来就开着。但转换超过 5-6 个文件的批量任务时，浏览器工具比折腾 Automator 更快。

6. 在 Windows 上转换 HEIC

Windows 是 HEIC 最让人头疼的地方。开箱即用的 Windows 10 和 11 没有扩展就打不开 HEIC 文件。

Microsoft HEIC 扩展

打开 Microsoft Store，搜索"HEIF Image Extensions"（免费，由 Microsoft 发布）并安装。再从同一发布者获取"HEVC Video Extensions"——售价 0.99 美元，但某些系统需要两者才能完整支持 HEIC。安装完成后，Windows 照片查看器和默认的"照片"应用就能处理 HEIC 文件了。然后你可以打开 HEIC 文件，使用"另存为"选项，选择 JPEG。

这方法可行。但批量转换很笨拙，而且一些较旧的 Windows 安装在使用该扩展时会出问题。我见过它在一台机器上完美运行，却在另一台相同 Windows 版本的机器上静默失败（原因不明）。

使用 PowerShell（适合技术达人）

如果你安装了 HEIF 扩展，又想转换整个文件夹而不点击图形界面，可以用 PowerShell 写脚本。这不是最友好的方法，但对 IT 人士或经常在 Windows 上批量处理 iPhone 照片的人来说很有效。

浏览器替代方案

说实话，对大多数 Windows 用户来说，浏览器转换器 是阻力最小的方案。不用安装应用商店扩展，没有兼容性烦恼，也不用纠结为什么这个 HEIC 能打开那个却打不开。拖入、转换、下载，搞定。

说真的，我用 Windows 多年了，别人发来一批 HEIC 照片时我还是会伸手用浏览器工具。它就是比指望 Windows 优雅地处理 Apple 的格式更靠谱。

7. 将 HEIC 转换为 JPEG 会损失画质吗？

事情是这样的——视情况而定。但对大多数实际用途来说？不会。

HEIC 是有损格式，和 JPEG 一样。把 HEIC 转成 JPEG 时，你是在对已经压缩过的图像重新压缩。理论上，每一代有损压缩都会降低质量。但实际上，HEIC 转 JPEG 的质量损失在大多数情况下肉眼根本看不出来。

你可能在以下情况注意到差异：大幅裁剪或放大查看精细细节（如照片中的文字、织物纹理或远处的小物体）。如果你是为社交媒体、网页或邮件转换照片，质量差异可以忽略不计。如果是为了大幅打印，或每像素都至关重要的专业摄影，你可能要坚持使用兼容 HEIC 的工作流，或者转成 PNG 而非 JPEG，以避免额外压缩。

转换器工具 上的质量滑块让你掌控这种权衡。在 95% 质量下，HEIC 转 JPEG 几乎与原图无法区分。在 70% 时，你可能在天空或肤色等平滑渐变中开始看到伪影。我一般用 85%——对网站和交付客户足够好，文件大小也合理。

哦，还有一点：转换后，你可能想为网页用途进一步 压缩生成的 JPEG，或把它们 缩放到 特定尺寸。iPhone 4800 万或 1200 万像素相机拍出的 HEIC 文件通常远大于网站所需。转成 JPEG 不会改变分辨率——4032x3024 的 HEIC 变成 4032x3024 的 JPEG。如果需要更小的尺寸，就在转换后再缩放。

什么时候不要把 HEIC 转成 JPEG

如果你是归档 RAW 文件的专业摄影师，或需要为大幅打印保留最高质量，请保留 HEIC 原片——转成 JPEG 会永久丢失数据。本指南面向只需要一个便于快速分享的版本的人，不适用于归档工作流。

另外，如果你用的是 Mac，又只和其他 Apple 用户分享，老实说没必要急着转换。他们本来就能原生打开 HEIC。把时间花在别的事上吧。具体情况因人而异，但如果你遇到上述任何一种情形，停下来重新考虑一下。

常见问题

安卓手机能打开 HEIC 文件吗？

较新的安卓手机（Android 9 及以上版本，并更新了 Google Photos）通常能处理 HEIC。旧款安卓设备一般不行。如果你要把照片发给某人，又不确定对方用什么手机，就先转成 JPEG。只需大约 5 秒，还能省去一句尴尬的"我打不开。"

HEIC 比 JPEG 更好吗？

从技术上讲是的——HEIC 在相近的视觉质量下压缩率更高，支持 16 位色彩（JPEG 只有 8 位），还能随图像一起存储深度图和动态数据。但"更好"不等于"更兼容"。JPEG 成为通用标准是有原因的：它哪里都能用。HEIC 理论上更好；但在需要与他人分享文件、上传到网站，或使用并非为 Apple 生态设计的工作流时，JPEG 在实践中更好。

转换时会丢失 EXIF 数据吗？

用 SmartImgKit 转换器 不会——它在转换过程中保留 EXIF 元数据（相机型号、日期、位置等）。有些在线转换器会剥离 EXIF 数据，如果你需要保留时间戳或位置信息，这就很要命。在本地处理的浏览器工具在这方面通常更好，因为它们不需要为服务器存储成本做优化。

我可以把 HEIC 转成 PNG 而不是 JPEG 吗？

完全可以，同一个转换器工具就支持。PNG 是无损的，能避免任何额外的压缩伪影。代价是文件大小——从 1200 万像素 HEIC 转出的 PNG 很容易达到 8-15MB，而同等 JPEG 可能只有 2-4MB。需要最高质量（存档、打印、透明背景）时用 PNG，文件大小重要时（网页、邮件、社交媒体）用 JPEG。

为什么我的 HEIC 照片转换后看起来不一样？

HEIC 支持的色域比标准 JPEG 更广。iPhone 拍摄的 HEIC 照片通常使用 Display P3 色彩空间，比 sRGB 更宽。转成 JPEG 时，图像会被映射到 sRGB，可能让颜色看起来略微没那么鲜艳。除非把两者并排对比，大多数人注意不到这点。对于对色彩要求严苛的工作，请转成 PNG，或使用支持带感知渲染意图的 P3 到 sRGB 映射的软件。

如何在 iPhone 本机上转换 HEIC 文件？

老实说？iOS 上最简单的方法：打开 HEIC 照片，点按"分享"按钮，选择"存储到文件"。这只是原样保存。要真正转换，最好的办法是在 Safari 中打开 转换器，从相册上传照片，再下载 JPEG。或者，你可以用"快捷指令"应用创建一个自动转换工作流——快捷指令库里有现成的快捷指令。总之，在相机格式里切换到"兼容性最好"才是永久解决办法。这方法对我有效，但你可能会找到别的办法。

准备好解决那些顽固的 HEIC 文件了吗？

别再和打不开的文件较劲了。几秒钟就能把 HEIC 转成 JPEG——无需上传、无需注册，照片始终留在你的设备上。
