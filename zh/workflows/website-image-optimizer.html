使用方法

1

添加图片

拖入网站目录中的所有图片。

2

选择格式和质量

WebP 80% 是大多数网站的最佳平衡点。

3

优化

点击开始优化，图片在浏览器中本地压缩。

4

上传到网站

下载 ZIP，替换服务器上的原图。

为什么选择本工具

大多数在线图片优化器会把你的文件上传到服务器，增加延迟和隐私风险。本工具使用 Canvas API 在浏览器本地完成所有处理——图片从不离开你的设备。压缩质量与 Squoosh 或 TinyPNG 相当，但支持批量导出 ZIP，完全免费。
