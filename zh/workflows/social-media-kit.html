此工作流的作用

Social Media Kit runs 3 operations in sequence on every uploaded image: (1) auto-crop to selected platform dimensions (Instagram 1080×1080, Facebook 1200×630, Twitter/X 1500×500, LinkedIn 1200×627) with white background, (2) optionally apply a style filter (sepia/grayscale), (3) optionally add a text watermark for brand protection. The result is one ZIP per run containing all platform variants for every uploaded image.

平台尺寸指南

Instagram: 1080×1080px（方形帖子）。 Facebook: 1200×630px（分享图）。 Twitter/X: 1500×500px（页头/横幅）。 LinkedIn: 1200×627px（分享图）。选择多个平台可一次上传获得所有尺寸。

最佳用例

  • 为活动创建统一的社交媒体图片
  • 为多平台上传缩放照片
  • 在所有社交平台添加统一品牌标识
  • 批量处理公司社交账号的团队照片
