一次生成 Amazon 主图 + 副图

Amazon 对商品图片有严格规范：主图必须是 2000×2000 的纯白底图，产品占画面 85%，不能有文字、Logo、水印；副图则可以展示场景、细节、尺寸。Amazon 商品图套件上传一张产品图，自动生成合规的主图（白底居中）和保留原样的副图，一套满足 Amazon 的图片要求。

对做亚马逊的卖家来说，图片合规是 listing 能否上架、能否获得曝光的基础。主图不合规会被平台压制甚至下架，而手动抠图、调白底既费时又容易出错。这个工具把最麻烦的主图处理自动化了。

几个实用技巧

主图白底要「够白」：Amazon 要求主图纯白背景（RGB 255,255,255）。拍摄时尽量用白底或浅色背景，工具处理白底的效果会更好。

产品占画面 85%：主图里的产品要足够大、居中，占比约 85%，买家在列表页小图里才看得清。

副图讲好「故事」：副图是展示产品价值的地方——场景图、细节图、尺寸图、对比图，尽量多放几张，能显著提升转化率。

主图不要加任何文字和 Logo：这是 Amazon 的硬性规定，主图上有文字、水印会被拒绝上架。文字和卖点放到副图里。

主图和副图的「分工」

很多卖家只重视主图，忽略副图，其实副图才是转化率的「主战场」。买家点进详情页后，会滑动看副图——场景图让买家想象产品在生活里的样子，细节图打消质量顾虑，尺寸图防止「到手比想象中小」的差评。副图做得好，能直接拉高转化、降低退货。

建议至少准备 5-7 张图：1 张主图 + 4-6 张副图。副图按「场景 → 细节 → 尺寸 → 对比 → 使用说明」的逻辑排列，形成一个完整的「说服链」。

局限与说明

本工具自动处理主图的白底和居中，但白底效果取决于原图背景的干净程度。如果原图背景杂乱、和产品颜色接近，自动去背景可能不完美，需要先做背景移除。最终上架前请以 Amazon 官方图片规范为准。全程浏览器本地处理，图片不上传。

常见问题

主图有什么硬性要求？ 纯白背景（RGB 255,255,255）、产品占画面 85%、无文字/Logo/水印、2000×2000。

副图可以展示什么？ 使用场景、细节特写、尺寸对比等，副图没有白底限制，是展示产品价值的空间。

原图背景不干净怎么办？ 建议先做背景移除，或拍摄时用干净的白底/浅色背景。

图片会上传吗？ 不会，处理在浏览器本地完成。
