使用方法

1

拖放图片

选择多张头像源图片（JPG/PNG/WebP）。单次最多 30 张。

2

配置 4 个步骤

设置圆形裁剪尺寸、可选滤镜、可选水印文字，并选择输出尺寸（64/128/256/512）。

3

运行流水线

点击“运行流水线”。引擎会按顺序对每张图片执行全部 4 个步骤。

4

下载 ZIP

所有 PNG（每张文件 × 所选每个尺寸）都打包到一个 ZIP，可即时下载。

详细使用指南

此流水线的作用

Avatar Pipeline runs 4 operations in sequence on every uploaded image: (1) circle crop to a perfect circle with transparent background, (2) optional filter (sepia/grayscale/blur), (3) optional watermark text, and (4) export at multiple standard avatar sizes (64/128/256/512). The result is one ZIP per run containing all combinations.

选择输出尺寸

Most platforms expect different avatar dimensions: Discord/Slack use 128-256px, GitHub uses 460px (pick 512 for best quality), Twitter uses 400px (pick 256 or 512), Gravatar uses 1-2048px (pick 512). Select multiple sizes if you plan to upload to several platforms.

为什么要透明背景？

透明 PNG 适用于任何平台背景（浅色或深色主题）。仅在确定目标为浅色界面时选“白色”，或为品牌背景选“自定义颜色”。

隐私与性能

所有处理都在浏览器中完成，不会向任何服务器上传图片。批量上限为单次 30 张，以保证普通笔记本的内存稳定。

最佳用例

  • 创建统一的社交媒体头像（Twitter、GitHub、Discord、Slack）
  • 为企业通讯录准备团队头像
  • 为项目生成 favicon 风格头像
  • 分享前为个人照片加水印
