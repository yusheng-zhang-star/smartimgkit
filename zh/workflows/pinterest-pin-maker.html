做一张 2:3 的 Pin 图

Pinterest 是一个靠「图」驱动的平台，Pin 图的尺寸和排版直接决定点击率。标准 Pin 图是 2:3 比例（推荐 1000×1500 像素），竖版长图在信息流里占据更大版面、更容易被注意到。Pinterest Pin 生成器把图片裁成标准比例，并支持叠加文字，帮你快速产出一张合格的 Pin 图。

对做跨境电商、独立站、内容营销的人来说，Pinterest 是重要的引流渠道——一张好看的 Pin 图能带来持续几个月甚至几年的自然流量。对国内做外贸、家居、穿搭、手工类内容的创作者，Pinterest 也是触达海外用户的重要阵地。

适合谁用

  • 跨境电商 / 独立站卖家：给产品做 Pin 图，引流到店铺。
  • 内容创作者 / 博主：把文章、教程做成 Pin 图，扩大传播。
  • 家居 / 穿搭 / 手工类账号：这些是 Pinterest 上的高热度品类。
  • 营销人员：批量制作品牌 Pin 图，投放 Pinterest 广告。

使用步骤

  1. 上传图片。
  2. 选择 2:3 比例，自动裁切。
  3. 叠加标题或关键词文字。
  4. 下载 Pin 图，发布到 Pinterest。

几个实用技巧

文字要够大：Pin 图在信息流里显示尺寸不大，标题文字要加粗、放大，让人一眼看清主题。文字颜色和图片背景要有足够对比度。

竖版长图更吸睛：2:3 是最稳妥的比例，太长的图（如 1:2.8）在信息流里会被折叠，反而影响完整展示。

图片要「美」：Pinterest 用户对审美很敏感，色彩明亮、构图干净的图点击率更高。家居、美食、旅行、穿搭类的高质量图天然适合这个平台。

Pinterest 的图片逻辑

Pinterest 和 Instagram 不同，它更像一个「图片搜索引擎」，用户是带着「找灵感、找商品」的意图来的。所以 Pin 图的文字要包含关键词（比如「北欧风客厅装饰」），方便被搜索到；图片本身则要足够美，才能在信息流里被点击。

一个 Pin 图的生命周期很长——好的 Pin 图能被反复收藏、传播几个月甚至几年。所以值得在图片质量和关键词上多花点心思，这是 Pinterest 营销里性价比最高的投入。

局限与说明

本工具做的是「图片裁剪到 2:3 比例 + 叠加文字」的基础功能，不涉及复杂的模板设计或去背景。它帮你把现有图片快速适配 Pinterest 的标准尺寸，设计上仍需要你自己把握。全程浏览器本地处理，图片不上传。

常见问题

Pin 图推荐什么尺寸？ 推荐 1000×1500 像素（2:3 比例），这是 Pinterest 官方建议的标准尺寸。

能加文字吗？ 能，支持叠加标题文字，方便传达主题。

横图能直接做 Pin 吗？ 可以，工具会自动裁切成 2:3 竖版，但横图裁成竖版可能损失画面，建议用竖版原图。

图片会上传吗？ 不会，处理在浏览器本地完成。
