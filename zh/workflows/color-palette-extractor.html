从图片里「偷」一套配色

设计师拿到一张参考图——某个品牌的官网、一张电影海报、一份你喜欢的海报设计——第一反应往往是：这配色真好看，但具体色值是多少？配色提取器解决的就是这件事。上传图片，它自动扫描画面里出现频率最高的颜色，按占比从高到低排出 8 个主色，并直接给出 HEX 色值和对应的 CSS 变量（--color-1 到 --color-8），复制即可用。

对做界面设计的人来说，这一组变量能直接粘进设计稿或前端样式表，省去在取色器和浏览器之间来回切换的麻烦。对做海报、PPT、公众号封面的人来说，它帮你把「感觉不错」的配色落成可复用的具体色值，下次做同系列内容时保持视觉统一。

适合谁用

  • UI / 前端开发者：从竞品截图或设计参考里快速拿到可用的 CSS 变量，搭页面时直接套用。
  • 平面 / 运营设计师：从一张喜欢的图里提取配色，用于海报、头图、落地页的统一风格。
  • 自媒体 / 博主：给自己的账号定一套固定配色，让封面、配图、排版看起来更有「品牌感」。
  • 品牌 / 电商：分析竞品主图用色，辅助自己的主图配色决策。

使用步骤

  1. 把图片拖进页面，或点击选择本地图片。
  2. 工具自动压缩采样，按颜色占比排序，生成 8 个主色色块。
  3. 色块下方直接显示 HEX 色值，右侧文本框里是整理好的 CSS 变量。
  4. 点「复制 CSS 变量」一键带走，粘进代码或设计稿即可。

几个实用技巧

想要更「干净」的配色？ 工具按像素占比取色，如果图里有大片白色背景或黑色文字，这些中性色可能挤进前几名。取色时尽量裁掉纯白/纯黑的大面积区域，或选一张色彩信息更集中的图。

主色不一定是「最显眼」的颜色：占比高的往往是背景或大色块，而真正作为品牌色的可能是面积小但饱和度高的一小块。拿到结果后，可以结合自己的判断，从 8 个颜色里挑出「主色 + 辅助色 + 点缀色」的搭配。

搭配中性色一起用：提取出的高饱和色适合做点缀，日常排版还需要灰阶来平衡。把提取的主色配上一组灰（#f8fafc 到 #0f172a），整套 UI 会高级很多。

配色提取 vs 专业取色

如果你只需要「某个像素点的颜色」，直接用取色器点一下更准；如果你要「整张图的配色倾向」，用本工具更合适——两者用途不同，可以配合使用。拿到提取的 8 个主色后，很多设计师会再手动微调几个色值，让它更符合品牌或情绪基调。

另一个实用思路是「反向配色」：先定好你想传达的情绪（比如沉稳、活泼、高级感），再去找符合这个情绪的参考图，用工具把它的配色提取出来，套用到自己的设计上。这样比凭感觉配色更高效，也更容易做出统一、有质感的视觉。

局限与说明

本工具做的是基于像素频率的抽样取色，不是专业的「色彩理论分析」，不会自动给出「最佳配色方案」建议。它诚实地把画面里真实存在的颜色量化和排序，最终怎么搭配仍由你决定。所有处理都在浏览器本地完成，图片不会上传。

常见问题

为什么提取出的颜色和我看到的不完全一样？ 工具按像素频率采样，视觉上最显眼的颜色不一定面积最大。提取结果反映的是「画面里出现最多的颜色」，而非「人眼最关注的局部颜色」。

一次提取几个颜色？ 默认提取 8 个主色。如果图片色彩简单，可能出现少于 8 个有效颜色的情况。

支持透明背景的 PNG 吗？ 透明像素不计入颜色统计，工具只统计有内容的区域。

图片会上传吗？ 不会。全部在浏览器本地处理，关闭页面后图片数据即释放。
