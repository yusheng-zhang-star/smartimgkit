一张大图切成 N 张小图

切图这件事，看起来简单，做起来却常让人抓狂：PS 里手动拉参考线、逐个导出、命名错乱……设计稿切图器把这件事自动化了。上传一张大图，设定横竖切几刀，它按网格把整图均匀切割成若干小图，打包成 ZIP 下载，每张按行列编号命名（如 r1c1、r1c2），顺序一目了然。

最常见的用途是 UI 切图：设计师把一整版图标、按钮状态或 banner 排在一张画布上，交给前端时切成一个个独立资源。其次是社交媒体拼图——把一张大图切成九宫格或横条，按顺序发到 Instagram 主页拼成完整画面。还有雪碧图（CSS sprite）的制作，把多个小图标拼成一张大图后再切成独立文件，减少网页请求数。

适合谁用

  • UI 设计师与前端：批量导出图标、按钮、状态图，命名规范统一。
  • 运营 / 新媒体：做九宫格、长图切条，适配不同平台的展示规则。
  • 游戏 / 动效：把序列帧大图切成单帧，导入动效软件。
  • 电商 / 品牌：把大尺寸 banner 切成平台要求的多个尺寸。

使用步骤

  1. 上传需要切割的大图。
  2. 设定横向和纵向的切割数量（如 3×3）。
  3. 工具按网格均匀切割，生成编号命名的小图。
  4. 下载 ZIP，按文件名顺序使用。

几个实用技巧

切图前先规划好网格：如果是九宫格拼图，正方形 + 3×3 最稳妥；如果是 UI 图标，建议图标之间留好间距，避免切割时压到相邻图标边缘。

分辨率要够：一张大图切成多块后，每块的实际像素会变小。如果目标是高清展示，源图分辨率要足够高（例如九宫格整图建议 3240×3240，切完每格 1080×1080）。

善用编号命名：工具输出的 r1c1、r1c2 命名是按「行-列」排列的。发九宫格时要理解目标平台的排列顺序（Instagram 是从右往左、从下往上），倒序发布才能拼对。

切图之外的准备工作

切图只是第一步，切完后的命名、归档、分发同样重要。建议切图前先想好命名规则（比如 icon-home、icon-search 这样的语义化命名），切完后按用途归类到不同文件夹，交付给前端时附一份简单的说明，能省去大量来回沟通。

如果切割的是 UI 资源，配合 2x、3x 多倍率导出（同一资源同时输出 @2x、@3x）能适配不同分辨率的屏幕。虽然本工具做的是固定网格切割，但理解了「一套资源要覆盖多倍率」这个思路，切图时就知道该把源图做得足够大。

局限与说明

本工具做的是均匀网格切割，不支持按自由形状或指定像素坐标精确裁切——那种需求更适合用带参考线和精确坐标的裁剪工具。切割是基于原始像素的等分，如果源图尺寸不能被网格数整除，边缘小块会略有像素差，属正常现象。全程浏览器本地处理，不上传图片。

常见问题

能切成不规则的块吗？ 不能，本工具是均匀网格切割。需要精确自定义裁剪建议用裁剪工具逐块处理。

切完的图会损失画质吗？ 不会。切割是像素级的无损操作，不重新压缩，画质与源图一致。

九宫格切图发 Instagram 要注意什么？ 必须倒序上传（先发右下角，最后发左上角），否则主页上拼不成完整大图。

支持导出什么格式？ 输出为 PNG 格式，保证透明区域和画质无损。
