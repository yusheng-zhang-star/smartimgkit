Kompresor Gambar

🗜️

Letakkan gambar di sini

atau klik untuk mencari

Mendukung JPG, PNG, WebP — hingga 50 gambar

Cara Menggunakan

1

Unggah Gambar

Letakkan beberapa gambar atau pilih folder.

2

Atur Kualitas

Atur penggeser kualitas (lebih rendah = file lebih kecil).

3

Tetapkan Lebar Maksimum

Opsi untuk mengubah ukuran gambar ke lebar maksimum.

4

Kompres dan Unduh

Klik "Kompres Semua" dan unduh sebagai ZIP.

Panduan Lengkap

Langkah 1: Unggah Gambar

Seret dan letakkan beberapa gambar.

Langkah 2: Atur Kualitas

Gunakan penggeser Kualitas untuk mengontrol kompresi.

Langkah 3: Tetapkan Lebar Maksimum (Opsi)

Masukkan lebar maksimum dalam piksel.

Langkah 4: Kompres dan Unduh

Klik "Kompres Semua" lalu klik "Unduh ZIP".

Kasus Penggunaan Terbaik

  • Optimasi web
  • Lampiran email
  • Penyimpanan cloud

Pertanyaan Umum

Ini untuk pemrosesan batch. Kompresor gambar tunggal memiliki pratinjau sebelum/sesudah.
Untuk JPG/WebP, ya. Penggeser kualitas memungkinkan Anda mengontrol keseimbangan.
Tidak. Seluruh kompresi terjadi secara lokal.
