Panduan Lengkap

Langkah 1: Periksa Dukungan Browser Anda

Bagian atas halaman menunjukkan browser Anda saat ini dan apakah dapat mendekode AVIF.

Langkah 2: Pilih Format Output

Pilih JPG (universal, file lebih kecil), PNG (lossless, lebih besar), atau WebP (seimbang).

Langkah 3: Atur Kualitas

Gunakan slider kualitas (10-100%) untuk mengontrol ukuran file output.

Langkah 4: Unggah File AVIF

Klik area unggah atau seret dan lepas file .avif. Maks 30MB per file.

Langkah 5: Konversi dan Unduh

Klik "Konversi" untuk memproses, lalu "Unduh" untuk menyimpan.

Ringkasan Dukungan Browser

  • Chrome 85+ — Full support
  • Firefox 93+ — Full support
  • Safari 16.4+ — Full support

Pertanyaan Umum

Chrome 85+, Firefox 93+, Safari 16.4+. Edge juga mendukung karena berbasis Chromium.
AVIF memiliki dukungan terbatas di media sosial dan browser lama. Mengonversi ke JPG memastikan gambar Anda bisa dilihat di platform mana pun.
Mengonversi AVIF ke JPG dengan kualitas 90-100% tetap mempertahankan kualitas visual dengan sangat baik.
