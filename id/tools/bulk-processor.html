How to Use the Bulk Image Processor

Batch process dozens of images in under a minute. Here's how:

1

Drop or Select Images

Drag and drop multiple image files, or click the upload area to browse. You can select as many files as you need.

2

Choose a Preset or Customize

Pick a quick preset (Web Optimized, Print Ready, E-Commerce, Thumbnail) or expand "Processing Options" for full control over resize, format, quality, and watermark.

3

Configure Batch Rename

Toggle "Rename output files" to set a naming pattern with prefix and auto-numbering (e.g. product_001.jpg).

4

Click Process All

Click the "Process All" button. Each file shows its own progress bar, and you'll see live before/after size comparisons.

5

Download ZIP Archive

Review the results, check compression savings, then click "Download ZIP" to get all processed images in one file.

Panduan Lengkap

Batch Resize

Masukkan lebar dan/atau tinggi target di bagian Ubah Ukuran. Dengan "Pertahankan rasio aspek" dicentang (default), alat secara otomatisly scales the other dimension. Leave both empty to keep original dimensions. This is perfect for normalizing product photos or creating uniform social media assets.

Tips: Jika Anda hanya memasukkan lebar, tinggi secara otomatis menyesuaikan untuk mempertahankan proporsi — tidak perlu perhitungan.

Batch Compress & Convert

Gunakan dropdown Format Output untuk mengonversi semua gambar ke JPG, PNG, atau WebP. JPG adalah pilihan terbaik untuk fotos (small file size), PNG preserves transparency, and WebP offers modern compression. The Quality slider (10-100%) lets you balance file size versus visual quality — 80-85% is the sweet spot for web use.

Tips: WebP sering dapat mengurangi ukuran file hingga 25-35% dibandingkan dengan JPG pada level kualitas yang sama.

Batch Watermark

Masukkan teks watermark, sesuaikan ukuran font dan opasitas, lalu pilih posisi (kanan bawah, kiri bawah, kanan atas, kiri atast, or center). Leave the text field blank to skip watermarks. Great for branding batch photos before publishing.

Tips: Jaga opasitas antara 20-40% untuk watermark yang profesional dan tidak mengganggu.

Batch Rename

Aktifkan "Ganti nama file output" dan atur awalan serta nomor awal. File akan dinamai secara berurutan: awalan_001.ext, prefix_002.ext, etc. The numbering is zero-padded (3 digits by default).

Tips: Gunakan awalan deskriptif seperti produk_, galeri_, atau foto_ for easy file organization.

Using Presets

Klik tombol preset apa pun untuk langsung mengonfigurasi beberapa pengaturan sekaligus:

  • Web Optimized — 80% quality, max 1200px width. Ideal for blog images, portfolio thumbnails, and website assets.
  • Print Ready — 100% quality, max 3000px. Best for photo printing, high-res archiving, and professional deliverables.
  • E-Commerce — 85% quality, max 1000px. Optimized for product listings on marketplaces like Amazon, eBay, or Shopify.
  • Thumbnail — 60% quality, max 300px. Perfect for preview images, avatars, or gallery thumbnails.

Setelah menerapkan preset, Anda masih dapat menyempurnakan pengaturan individual di panel Opsi Pemrosesan.

Kasus Penggunaan Terbaik

  • Social media content — standardize image sizes and formats for multiple platforms
