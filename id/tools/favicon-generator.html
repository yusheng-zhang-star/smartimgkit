Panduan Lengkap

Langkah 1: Unggah Gambar Persegi

Seret dan lepas gambar persegi. PNG dengan transparansi paling cocok.

Langkah 2: Pratinjau Semua Ukuran

Alat ini menghasilkan semua ukuran favicon standar: 16×16, 32×32, 48×48, 64×64, 96×96, 128×128, 256×256, dan 512×512.

Langkah 3: Unduh ZIP

Klik "Unduh ZIP" untuk mendapatkan paket lengkap.

Langkah 4: Tambahkan ke Situs Anda

Ekstrak paket ke direktori root situs Anda. Salin potongan HTML ke tag <head> Anda.

Mengapa Banyak Ukuran?

  • 16×16, 32×32 — Browser tab and bookmark icons
  • 180×180 — iOS home screen
  • 192×192, 512×512 — Android home screen and PWA splash

Pertanyaan Umum

16x16 hingga 512x512, apple-touch-icon, favicon.ico multi-ukuran.
Tidak. Semua pembuatan di browser Anda.
Ini untuk favicon web (ukuran tetap + HTML). ICO untuk ikon desktop.
