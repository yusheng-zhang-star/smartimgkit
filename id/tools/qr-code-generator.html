Panduan Pengguna Detil

Langkah 1: Pilih Jenis Konten

Pilih satu dari: URL, Teks, WiFi, vCard, atau Email.

Langkah 2: Isi Konten

Masukkan data yang relevan untuk jenis yang dipilih.

Langkah 3: Sesuaikan Tampilan

Atur warna latar depan/belakang, tingkat koreksi kesalahan, dan ukuran.

Langkah 4: Tambah Logo Tengah (Opsional)

Unggah PNG, JPG, atau SVG untuk ditempatkan di tengah kode QR.

Langkah 5: Undus

Klik "Unduh PNG" untuk raster atau "Unduh SVG" untuk vektor.

Langkah 6: Batch (Opsional)

Klik "Tambah ke Batch" untuk mengantri kode QR lain, lalu unduh semua sebagai ZIP.

Tingkat Koreksi Kesalahan

  • L (7%) — Kode terkecil
  • M (15%) — Default
  • Q (25%) — Dengan logo
  • H (30%) — Kekokohan maksimum
