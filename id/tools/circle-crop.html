Panduan Lengkap

Langkah 1: Unggah Gambar Anda

Klik dropzone atau seret dan lepas file gambar apa pun. JPG, PNG, WebP, dan BMP semuanya didukung. Gambar akan dimuat ke kanvas untuk diedit.

Langkah 2: Posisikan Lingkaran

Gunakan slider Ukuran untuk mengontrol seberapa besar lingkaran (10% hingga 100% dari gambar). Gunakan slider Offset untuk menggeser lingkaran secara horizontal dan vertikal — berguna saat subjek tidak di tengah.

Langkah 3: Pilih Latar Belakang

  • Transparent — Best for avatars and overlays.
  • White — For documents or slides.
  • Custom Color — Match your brand.

Langkah 4: Unduh

Klik "Unduh PNG" untuk menyimpan. Format PNG mempertahankan alfa (transparansi).

Kasus Penggunaan Umum

  • Social media avatars
  • LinkedIn profile
  • Team directories
  • App icons
