Panduan Lengkap

Langkah 1: Unggah atau Tempel SVG

Anda dapat mengunggah file .svg dengan menyeretnya ke zona jatuh, atau beralih ke tab "Tempel Kode SVG" dan tempel markup SVG mentah. Ini berguna saat Anda memiliki kode SVG dari Figma, Sketch, Adobe Illustrator, atau SVG tulisan tangan.

Langkah 2: Pilih Format Output

Pilih format output yang sesuai dengan kebutuhan Anda:

  • PNG: kompresi tanpa kehilangan dan mendukung transparansi. Cocok untuk aset antarmuka, logo, dan ikon.
  • JPG: file lebih kecil tetapi tanpa transparansi. Lebih cocok untuk ilustrasi kompleks dengan banyak warna.
  • WebP: format modern dengan kompresi sangat baik. Pilihan terbaik untuk web.

Langkah 3: Atur Faktor Skala

Faktor skala mengontrol resolusi output:

  • 1x: dimensi piksel sama dengan lebar dan tinggi SVG
  • 2x: resolusi dua kali lipat — pas untuk layar retina (aset @2x)
  • 3x: resolusi tiga kali lipat — untuk layar DPI tinggi
  • 4x: resolusi empat kali lipat — untuk kualitas cetak

Karena SVG adalah format vektor, memperbesar tidak menghasilkan kehilangan kualitas. SVG 100×100 pada skala 4x menghasilkan PNG 400×400 yang tajam.

Langkah 4: Unduh

Klik Unduh untuk menyimpan gambar yang dirasterisasi. File dihasilkan sepenuhnya di browser Anda — tanpa pemrosesan server.

Kasus Penggunaan Terbaik

  • Desainer UI/UX: ekspor ikon SVG ke PNG sebagai aset aplikasi Android/iOS
  • Pengembang web: ubah SVG inline menjadi gambar statis untuk tag <img> atau background-image di CSS
  • Desainer cetak: ubah logo SVG ke PNG resolusi tinggi (skala 4x) untuk bahan cetak
  • Presentasi: ubah grafik SVG ke PNG untuk PowerPoint atau Keynote
  • Media sosial: ubah ilustrasi SVG ke PNG untuk kiriman Instagram atau Facebook

Tips Profesional

  • Untuk aset @2x yang tajam di aplikasi seluler, atur faktor skala ke 2x dan ekspor sebagai PNG
  • Jika SVG Anda memiliki transparansi, gunakan format PNG agar tetap terjaga
  • Untuk ukuran file terkecil dengan kualitas baik, gunakan WebP pada skala 2x
  • Elemen <text> SVG bisa tampil berbeda antar peramban — konversi ke PNG untuk mengunci font
  • Untuk cetak, gunakan skala 4x + PNG demi kualitas maksimal
  • Anda bisa menempelkan kode SVG langsung — praktis untuk konversi sekali pakai tanpa menyimpan file

Pertanyaan Umum

Tidak ada batas ukuran file yang ketat. Namun, SVG yang sangat besar (mis., 2000×2000+ piksel pada skala 4x) mungkin membutuhkan waktu lebih lama untuk dirender.
Ini bisa terjadi jika SVG Anda menggunakan sumber daya eksternal (gambar tertaut, font) atau gaya CSS yang tidak disematkan. Untuk hasil terbaik, gunakan kode SVG mandiri.

PNG pada skala 2x atau 3x, karena masing-masing toko aplikasi menuntut ukuran tetap (misalnya 512×512). PNG juga menyimpan transparansi, jadi ikon tetap rapi di latar terang maupun gelap.
