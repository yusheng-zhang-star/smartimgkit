Panduan Lengkap

Langkah 1: Unggah PDF

Klik area unggah dan pilih file PDF.

Langkah 2: Pilih Rentang Halaman

Pilih "Semua halaman" atau tentukan rentang seperti "1-5".

Langkah 3: Pilih Format Output

Pilih JPG, PNG, atau WebP.

Langkah 4: Atur Resolusi

Pilih 72 DPI (layar) hingga 300 DPI (kualitas cetak).

Langkah 5: Konversi

Klik "Konversi ke Gambar". Setiap halaman dirender menjadi gambar.

Langkah 6: Unduh

Klik "Unduh Semua ZIP" untuk mendapatkan semua halaman.

Pengaturan Terbaik per Kasus

  • Social media — JPG, 150 DPI
  • Print — PNG, 300 DPI
  • OCR — PNG, 300 DPI

Pertanyaan Umum

PDF 1.0 hingga 2.0. PDF password tidak didukung.
Hingga 200 halaman direkomendasikan.
Tidak. Rendering dengan pdf.js di browser.
