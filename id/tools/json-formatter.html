🔧 Format JSON

Cara Memakai

1

Tempel JSON

Salin respons API, isi berkas konfigurasi, atau data apa pun dalam format JSON ke kotak masukan. Enter dan indentasi acak tidak menjadi masalah.

2

Pilih tindakan

Rapikan dengan 2 spasi untuk gaya yang umum di dokumentasi, 4 spasi bila Anda terbiasa dengan lekukan lebar, atau Padatkan untuk membuang semua spasi.

3

Periksa bila perlu

Tombol Periksa hanya menilai apakah JSON valid tanpa mengubah isinya. Pesan galat menyebut posisi karakter yang bermasalah.

4

Salin hasilnya

Hasil muncul di kotak kedua. Salin dengan tombol Salin, atau blok dan salin manual bila perlu bagian tertentu saja.

Panduan Lengkap

Membaca pesan galat dengan cepat

Pesan galat dari JSON menyebut posisi karakter, misalnya pada karakter ke-182. Untuk menemukannya, tempelkan teks ke editor yang menampilkan posisi kursor, lalu lompat ke angka tersebut; hampir selalu penyebabnya koma berlebih di akhir objek, tanda kutip tunggal yang dipakai untuk string, atau nama kunci yang tidak diapit tanda kutip.

Dua spasi atau empat spasi

Dua spasi adalah gaya yang dipakai di sebagian besar dokumentasi dan contoh kode, sehingga cocok bila hasilnya akan ditempel ke panduan atau dikirim ke orang lain. Empat spasi memudahkan membaca data bertingkat dalam di editor yang barisnya panjang. Untuk disimpan kembali sebagai berkas, bedanya tidak berpengaruh pada apa pun selain ukuran.

Padatkan untuk menghemat ruang

Membuang spasi dan baris baru bisa memangkas ukuran JSON menjadi sepertiga tanpa mengubah isinya sama sekali. Ini berguna saat data akan disisipkan ke dalam kode, dikirim lewat URL, atau ditempel ke kolom konfigurasi yang tidak menerima baris baru.

Hal yang bisa hilang saat JSON diproses

Proses rapikan dan padatkan membaca JSON lalu menuliskannya kembali. Dalam proses itu, kunci yang muncul dua kali dalam satu objek akan menyusut menjadi satu karena hanya nilai terakhir yang disimpan, dan angka yang sangat besar bisa kehilangan presisi karena dibaca sebagai bilangan pecahan. Untuk data yang memuat angka identitas sangat panjang, periksa hasilnya sebelum dipakai.

Urutan kunci tidak dijamin

JSON secara resmi tidak mengatur urutan kunci, dan proses baca-tulis ulang bisa mengubah urutan tampil. Bila urutan penting untuk dibaca manusia, susun ulang secara manual setelah dirapikan; untuk diproses mesin, urutan tidak berpengaruh.

Kapan memakai halaman ini dan kapan tidak

Halaman ini bekerja sepenuhnya di browser, jadi aman untuk JSON berisi token atau data pribadi yang tidak boleh dikirim ke server mana pun. Namun ia tidak menyunting nilai, tidak mencari kunci, dan tidak membandingkan dua JSON. Untuk keperluan itu diperlukan alat lain.

Contoh nyata: respons API yang dikirim vendor

Vendor pembayaran atau layanan logistik di Indonesia sering mengirim dokumentasi dalam bentuk satu blok JSON panjang tanpa lekukan, atau justru dengan lekukan yang kacau karena ditempel dari PDF. Tempelkan saja ke kotak masukan lalu tekan Rapikan; setelah itu struktur seperti data transaksi, status pengiriman, dan kode kurir jadi mudah dibaca satu per satu. Untuk membagikan contoh ke tim lewat WhatsApp, versi Padatkan lebih aman karena tidak terpotong menjadi banyak pesan.

Contoh nyata: berkas konfigurasi proyek

Pada proyek Laravel, Node, atau Flutter, berkas seperti composer.json, package.json, dan pubspec.yaml versi JSON kerap rusak karena koma berlebih saat diedit manual. Sebelum menjalankan perintah build, tempelkan isinya ke sini dan tekan Periksa. Bila valid, salin kembali hasil yang sudah dirapikan agar diff di Git hanya menampilkan perubahan yang benar-benar disengaja, bukan seluruh berkas berubah karena indentasi.

Pertanyaan yang Sering Diajukan

Tidak. Seluruh proses berjalan di browser memakai fungsi bawaan JavaScript, sehingga data tidak pernah meninggalkan perangkat.
Pesan itu menyebut posisi karakter yang bermasalah. Penyebab tersering adalah koma berlebih di akhir objek, tanda kutip tunggal, atau nama kunci tanpa tanda kutip.
Rapikan menambah baris baru dan indentasi agar mudah dibaca. Padatkan membuang semua spasi dan baris baru agar berkas sekecil mungkin. Isinya tetap sama.
Bisa. JSON tidak menjamin urutan kunci, dan proses baca-tulis ulang dapat mengubah urutan tampil. Untuk diproses mesin, hal ini tidak berpengaruh.
Hanya nilai terakhir yang disimpan, karena prosesnya membaca JSON menjadi objek lalu menuliskannya kembali. Periksa hasilnya bila data berasal dari sumber yang tidak terkendali.
Angka yang melebihi batas bilangan aman JavaScript bisa kehilangan presisi saat dibaca. Untuk data berisi nomor identitas sangat panjang, jangan andalkan hasil alat ini sebagai rujukan akhir.
Tidak di halaman ini. Yang tersedia hanya merapikan, memadatkan, dan memeriksa keabsahan.
