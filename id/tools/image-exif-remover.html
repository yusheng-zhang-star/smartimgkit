Panduan Lengkap

Langkah 1: Unggah Gambar Anda

Klik dropzone atau seret dan lepas file gambar (JPG, PNG, atau WebP). Foto yang diambil dengan smartphone atau kamera biasanya mengandung metadata EXIF. Alat ini akan mendeteksi dan menampilkan metadata yang ditemukan.

Langkah 2: Hapus Metadata EXIF

Klik "Hapus EXIF" untuk menghapus semua metadata tersembunyi dari gambar. Ini termasuk:

  • GPS location — Precise coordinates where the photo was taken
  • Camera info — Make, model, lens, and camera settings
  • Timestamp — Date and time the photo was taken
  • Software info — Editing software and version
  • Copyright — Copyright notice and artist info
Privacy Tip: Always remove EXIF before sharing photos online. GPS data can reveal your home address, daily routine, and private locations.

Langkah 3: Unduh Gambar Bersih

Setelah pemrosesan, klik "Unduh" untuk menyimpan gambar bersih sebagai file PNG. Format PNG memastikan tidak ada metadata yang dapat disematkan kembali saat penyimpanan.

Mengapa Hapus EXIF?

  • Privacy — Prevent strangers from knowing where and when you took a photo
  • File size — EXIF can add 10-50KB per image; removing it makes files smaller
  • Security — Some EXIF fields reveal software versions, which can be exploited
  • Anonymity — Remove copyright and author info before sharing
