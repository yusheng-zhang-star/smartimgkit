Panduan Lengkap

Langkah 1: Unggah Gambar Persegi

Seret dan letakkan gambar persegi. PNG dengan transparansi berfungsi paling baik.

Langkah 2: Pilih Ukuran

Aktifkan chip ukuran. File ICO akan berisi persis ukuran yang dipilih.

Langkah 3: Sesuaikan Rendering

Konfigurasi penskalaan, sudut melengkung, latar belakang, dan padding.

Langkah 4: Pratinjau

Setiap ukuran yang dipilih dirender dalam grid pratinjau.

Langkah 5: Unduh

Klik "Unduh ICO" untuk file tunggal, atau "Unduh ZIP Paket" untuk setiap ukuran sebagai PNG.

Format File ICO

ICO adalah format wadah yang dapat menyimpan beberapa ukuran gambar dalam satu file. Setiap entri adalah gambar lengkap (ICO modern menggunakan PNG).
