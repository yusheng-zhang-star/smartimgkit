SmartImgKit API

Free image processing API for developers. No API key required. All processing runs in the user's browser, which means zero server costs for you and complete privacy for your users.

1. URL Parameter API (Instant)

Load any tool with a pre-filled image URL. Perfect for integrations where you want to send users directly to a tool with their image already loaded.

https://smartimgkit.com/tools/compressor?url=https://example.com/photo.jpg
https://smartimgkit.com/tools/resizer?url=https://example.com/photo.jpg&w=800
https://smartimgkit.com/tools/converter?url=https://example.com/photo.jpg&to=webp

Parameters:

  • url — Image URL to auto-load (CORS-permitted images work best)
  • w, h — Target dimensions (resizer only)
  • to — Target format: webp, jpeg, png (converter only)

2. Image Info API

Get image metadata (dimensions, format, file size) as JSON.

GET/api/info?url=IMAGE_URL

curl "https://smartimgkit.com/api/info?url=https://example.com/photo.jpg"

{
  "width": 1920,
  "height": 1080,
  "type": "image/jpeg",
  "size": 2458392,
  "ok": true
}

3. JavaScript SDK (Browser)

Embed image processing directly in your web app using our open-source browser-based approach. No server needed.

<script src="https://smartimgkit.com/js/imkit-sdk.js"></script>
<script>
  // Compress an image file to WebP
  const blob = await IMKit.compress(file, { format: 'webp', quality: 0.8 });
  // blob is the compressed image — send it anywhere
</script>

The SDK is a thin wrapper around Canvas API and WebCodecs. Your users' images never touch our servers.

Pricing & Rate Limits

  • Free forever — no API key, no signup, no credit card
  • No rate limits — because processing happens client-side
  • No file size limit — same as the main tools

We believe image processing should be free and private. If you need higher-volume server-side processing, consider self-hosting our open-source engine.

What's Not Included

We don't offer server-side AI processing (background removal, super-resolution) via API yet. Those require GPU infrastructure and will be a paid tier. For now, use the browser tools directly.
