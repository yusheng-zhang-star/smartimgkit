SmartImgKit API

SmartImgKit currently exposes a single, simple API endpoint: the Image Info API. All image processing tools (compress, resize, convert, remove background) run client-side in the browser and are not yet available as a server-side or embeddable SDK. This page documents only what is live today.

Image Info API

Get image metadata (dimensions, format, file size) as JSON. No API key required.

GET/api/info?url=IMAGE_URL

curl "https://smartimgkit.com/api/info?url=https://example.com/photo.jpg"

{
  "width": 1920,
  "height": 1080,
  "type": "image/jpeg",
  "size": 2458392,
  "ok": true
}

Parameters:

  • url — The image URL to inspect (required). The server fetches only the image header to determine dimensions and format.

Response: width, height (pixels), type (MIME type), size (bytes), ok (boolean). On error, ok is false with an error message and an appropriate HTTP status.

Pricing & Rate Limits

  • Free forever — no API key, no signup, no credit card
  • No rate limits — because processing happens client-side
  • No file size limit — same as the main tools

We believe image processing should be free and private. If you need higher-volume server-side processing, consider self-hosting our open-source engine.

What's Not Included

We don't offer server-side AI processing (background removal, super-resolution) via API yet. Those require GPU infrastructure and will be a paid tier. For now, use the browser tools directly.
