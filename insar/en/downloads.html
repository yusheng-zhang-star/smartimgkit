Reproducibility

The sample files are generated by a fixed-seed script in the project repository, so every copy is identical and the expected results in the guide hold for every download. If a file you downloaded reproduces different numbers, you have found a bug — and we would genuinely like to hear about it.

Sample data is synthetic and must never be cited as survey evidence. This toolkit provides preliminary geotechnical interpretation only; results cannot replace licensed site investigation. Field verification by qualified professionals is required for all engineering decisions.
