What this workflow does

Social Media Kit runs 3 operations in sequence on every uploaded image: (1) auto-crop to selected platform dimensions (Instagram 1080×1080, Facebook 1200×630, Twitter/X 1500×500, LinkedIn 1200×627) with white background, (2) optionally apply a style filter (sepia/grayscale), (3) optionally add a text watermark for brand protection. The result is one ZIP per run containing all platform variants for every uploaded image.

Platform size guide

Instagram: 1080×1080px (square post). Facebook: 1200×630px (share image). Twitter/X: 1500×500px (header/banner). LinkedIn: 1200×627px (share image). Select multiple platforms to get all sizes from one upload.

Best use cases

  • Creating matching social media images for a campaign
  • Resizing a photo for multiple platform uploads
  • Adding consistent branding across all social platforms
  • Batch processing team photos for company social accounts
