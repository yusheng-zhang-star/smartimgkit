Detailed User Guide

What this pipeline does

Avatar Pipeline runs 4 operations in sequence on every uploaded image: (1) circle crop to a perfect circle with transparent background, (2) optional filter (sepia/grayscale/blur), (3) optional watermark text, and (4) export at multiple standard avatar sizes (64/128/256/512). The result is one ZIP per run containing all combinations.

Choosing output sizes

Most platforms expect different avatar dimensions: Discord/Slack use 128-256px, GitHub uses 460px (pick 512 for best quality), Twitter uses 400px (pick 256 or 512), Gravatar uses 1-2048px (pick 512). Select multiple sizes if you plan to upload to several platforms.

Why transparent background?

Transparent PNG works on any platform background (light or dark themes). Pick "White" only if you know the destination is a light UI, or "Custom color" for branded backgrounds.

Privacy & performance

All processing happens in your browser. No images are uploaded to any server. Batch limit is 30 images at once to keep memory usage stable on typical laptops.

Best use cases

  • Creating matching social media avatars (Twitter, GitHub, Discord, Slack)
  • Preparing team profile pictures for a corporate directory
  • Generating favicon-style avatars for a project
  • Watermarking personal photos before sharing
