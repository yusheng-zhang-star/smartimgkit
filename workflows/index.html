What "Use Cases" actually are

Single tools solve single steps — crop, resize, compress, remove a background. Real work is almost never a single step. A product listing needs a white background, a resize, and a format change. A client gallery needs watermarking, compression, and EXIF stripping. A social campaign needs one image in six different aspect ratios.

Use Cases chain those steps together into a single workflow, so you upload once and get the finished set back — a ZIP of Amazon-ready images, a complete avatar package, or every social size in one download. It is the difference between running five tools in sequence and clicking once.

Why chain tools instead of running them separately?

Every manual hand-off between tools is a place for mistakes to creep in — a missed step, a wrong export setting, a file named inconsistently. A workflow removes those hand-offs by doing the whole pipeline in one deterministic pass. You get consistency (every image treated identically), speed (one upload, one download), and fewer errors.

How these differ from the standalone tools

The standalone tools are the building blocks. The workflows are the recipes. They combine the same in-browser, privacy-first processing into purpose-built pipelines for specific jobs — Amazon listings, Etsy shops, YouTube thumbnails, resumes, and more. If a workflow exists for your task, it is almost always the faster path than assembling the steps yourself.

Everything stays in your browser

Every workflow runs 100% client-side, exactly like the single tools. Your images are processed on your own device and never uploaded to a server, which matters a lot when you are working with unpublished product photos, client work, or personal images. Privacy is not a premium feature here — it is the default.

How to pick the right workflow

Start from the outcome, not the tool. Shipping an Amazon listing? Use the Amazon workflow. Preparing a resume? Use the resume workflow. Building a YouTube channel? Use the thumbnail workflow. If you are not sure which one fits, look for the workflow whose output matches what you are trying to publish, and it will usually be the right starting point.

What is not here yet

Custom, user-built workflows are on the roadmap but not yet available. For now, every Use Case is pre-built and maintained to cover a specific, common job. If the workflow you need is not listed, the underlying single tools can still get the job done — just with a few extra manual steps.

How Use Cases Differ from Single Tools

Single tools (in Tools) do one thing well. Use Cases chain multiple tools together for tasks that normally require opening 3-5 browser tabs, exporting intermediate results, and re-importing them. With a workflow, you upload once and get the final packaged output in one ZIP.

Example: The Avatar Pipeline runs circle crop → filter → watermark → resize×4 on every image, then bundles 4 sizes × N images into one downloadable ZIP — replacing 4 manual tool runs.
