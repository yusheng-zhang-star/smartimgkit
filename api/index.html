SmartImgKit Developer API

The short answer: Embed professional image processing directly into your web app with a few lines of JavaScript. All processing runs in the user's browser — no server upload, no bandwidth costs, no API keys required. 100% free forever.

🚀 Quick Start (30 seconds)

// Load the SDK from our CDN <script src="https://smartimgkit.com/js/sdk.min.js"></script> // Compress an image file <script> const result = await SmartImgKit.compress(file, { quality: 0.8, maxWidth: 1920, format: 'webp' }); console.log('Saved:', file.size - result.size, 'bytes'); download(result, 'compressed.webp'); </script>

📦 Available Methods

compress SmartImgKit.compress(file, options)

Compress JPG/PNG/WebP images with adjustable quality. Returns a Blob.

options = { quality: 0.8, // 0.1 - 1.0 maxWidth: 1920, // optional format: 'webp' // jpeg | png | webp | avif }
resize SmartImgKit.resize(file, width, height)

Resize an image to exact dimensions. Returns a Blob.

convert SmartImgKit.convert(file, targetFormat)

Convert between JPG, PNG, WebP, AVIF. targetFormat = 'jpeg' | 'png' | 'webp' | 'avif'.

crop SmartImgKit.crop(file, x, y, width, height)

Crop an image to a rectangle. All values in pixels.

❓ FAQ

Is the SDK really free for commercial use?

Yes. MIT-style license. Use it in commercial SaaS, client work, or internal tools — no attribution required.

Do images get uploaded to your server?

No. The entire SDK runs in the browser using Canvas and WebAssembly. Your users' files never touch our servers.

Which browsers are supported?

All modern browsers: Chrome, Firefox, Safari 14+, Edge. AVIF support requires Chrome 85+ / Firefox 93+.

Is there a server-side API?

Not yet. The current SDK is browser-only — which is actually a feature, not a limitation.
