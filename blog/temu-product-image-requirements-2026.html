Main images vs detail images: different rules

A lot of sellers get confused because they apply the white-background rule to every single image, which makes their listings boring and hurts conversion. The rules are different for the main image vs the rest of the gallery:

  • Main image (the first one shoppers see in search): Must be 100% pure white background, no props, no text, no logos, no lifestyle context, product fills 85% of the frame. This is the one that gets auto-rejected if it's wrong.
  • Detail images 2-8: These can be lifestyle shots, size charts, close-ups of product details, infographics with text, even images on colored backgrounds. Temu actually rewards listings that use these to explain product features — sellers who add 3-4 detail images with size charts see a 20% lift in conversion, because shoppers trust them more.

Temu vs Amazon: what's different?

Both platforms want white-background main images, but Temu is slightly more lenient in some ways and stricter in others:

  • Temu allows more promotional text on detail images. Amazon bans almost all text overlays, but Temu actually encourages size charts, feature callouts, and "what's in the box" graphics on images 2-5.
  • Temu's background detection is stricter. Amazon tolerates a very soft shadow under the product; Temu's AI will flag even a faint gray shadow on the main image.
  • Both require minimum 800px for zoom, but Temu's algorithm rewards faster-loading images more. Since most Temu shoppers are on mobile, a 200KB compressed image ranks higher than a 5MB high-res file that takes 5 seconds to load.

Common mistakes new Temu sellers make

  • Uploading iPhone HEIC files directly. Temu doesn't accept HEIC; convert to JPG first in our resizer.
  • Putting the product in clear packaging on the main image. The packaging reflection triggers rejection — photograph the product itself, not the sealed box.
  • Using the same supplier photo everyone else uses. Temu flags duplicate product images, and your listing will get buried. Add a slight angle or a detail shot to make it unique.
  • Leaving props in the frame. A plant, a desk, a hand holding the product on the main image = automatic rejection.
