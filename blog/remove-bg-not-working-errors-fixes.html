Developer & API-Specific Errors

If you integrated remove.bg into your own application, the error patterns are different from consumer-side issues. Here's what developers are reporting:

A

API key returns "invalid_key"

Your API key is being rotated as part of the Leonardo.Ai migration. Check your email for a migration notice. If you don't receive one within a week, assume the key is permanently revoked and plan the Leonardo.Ai integration immediately.

B

Requests timeout after 60 seconds

The remove.bg API timeout was always 60 seconds for free tiers. Now it's hitting that limit consistently because the backend is overloaded with migration traffic. Retry logic with exponential backoff helps, but you should treat this as a signal to migrate rather than a transient issue.

C

Batch endpoints returning 200 but empty bodies

A known issue during the wind-down: the API acknowledges the request but never processes the image. The response looks successful but contains no image data. Add a check for empty response bodies and treat them as failures.

D

Webhook notifications stopped firing

remove.bg disabled webhook delivery as part of the migration. If your workflow relied on webhooks to trigger downstream processing, you'll need to switch to polling or migrate to Leonardo.Ai's webhook system.

FAQ: Your Questions, Answered

Why does remove.bg work sometimes and not others?

The shutdown process is gradual. Canva is moving traffic and server capacity in batches. Some requests still hit old infrastructure that works; others hit decommissioned servers that don't. That's why a reload sometimes "fixes" it — you got lucky on the next request.

Will VPN help fix remove.bg errors?

No. The problem is not regional blocking or IP bans. It's server-side decommissioning. A VPN routes your request to a different exit point, but it still lands on the same broken backend. Don't waste time on this.

My remove.bg account still has credits. Can I get a refund?

No. remove.bg's terms of service explicitly state that purchased credits are non-refundable and expire on the shutdown date. They will not transfer to Canva or Leonardo.Ai. Use them or lose them.

Is there a cached or archived version of remove.bg that still works?

Browser caches and Wayback Machine snapshots may show old pages, but they won't process images — the AI backend is required for that. Any "downloadable remove.bg" clone you find online is either a fake, a malware bundle, or another cloud tool with its own shutdown risk.

What about the remove.bg Chrome extension I installed months ago?

It will stop working when the API shuts down. See our Chrome extension alternatives guide for replacements. Uninstall it now to avoid broken right-click menu items.
