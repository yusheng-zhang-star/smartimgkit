Why Is Your PDF So Large?

PDFs get large for three main reasons: (1) High-resolution images — a scanned document at 600 DPI can be 20MB per page. (2) Embedded fonts — custom fonts add hundreds of KB each. (3) Version history — some editors save every edit version inside the PDF. A good compressor optimizes images, removes redundant data, and subsets fonts.

Expected results by PDF type:
• Scanned documents: 70-90% reduction
• Image-heavy reports: 50-70% reduction
• Text-only documents: 10-30% reduction
• Already-optimized PDFs: minimal change
