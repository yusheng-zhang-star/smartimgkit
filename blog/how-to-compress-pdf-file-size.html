Why Is Your PDF So Large?

PDFs get large for three main reasons: (1) High-resolution images — a scanned document at 600 DPI can be 20MB per page. (2) Embedded fonts — custom fonts add hundreds of KB each. (3) Version history — some editors save every edit version inside the PDF. A good compressor optimizes images, removes redundant data, and subsets fonts.

Expected results by PDF type:
• Scanned documents: 70-90% reduction
• Image-heavy reports: 50-70% reduction
• Text-only documents: 10-30% reduction
• Already-optimized PDFs: minimal change

What Gets Compressed?

A PDF file is a container that can hold many different types of data. Here is what contributes to file size and what compression does:

  • Images (60-90% of size). Scanned pages and embedded photos are the biggest factor. Compression downsamples them to 150-200 DPI and re-encodes as JPEG.
  • Fonts (5-20% of size). Embedded fonts can be large. Compression subsets fonts to only include characters actually used.
  • Metadata (1-5%). Author name, creation date, software info, and thumbnails. Compression strips unnecessary metadata.
  • Version history (0-30%). Some PDFs save every edit version. Compression removes all but the latest version.

When Not to Compress

Do not compress PDFs that contain:

  • Legal documents where every pixel must be preserved for evidentiary purposes.
  • Print-ready files with 300 DPI images and CMYK color — compression may degrade print quality.
  • Forms with interactive fields — some compressors break form functionality.
  • Signed documents — compression may invalidate digital signatures.

For these cases, use the Low compression setting, which applies minimal optimization while preserving document integrity.
