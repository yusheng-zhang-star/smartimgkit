The Best remove.bg Alternatives for Windows PCs, Tested Without Bias

remove.bg is going dark on December 1. If you're on Windows 11 or Windows 10, here's what actually works — no subscription, no Sketchbook, no guessing.

By the SmartImgKit editorial team September 23, 2026 11-minute read

If you're a Windows user who relied on remove.bg for quick background removal, you've probably noticed something: remove.bg never shipped a proper Windows desktop app. It was always a website and a Chrome extension. Now that both are disappearing, Windows users are left holding the bag — and the Windows Store is full of low-quality "background remover" apps that charge $4.99 and inject ads.

I've spent the past two weeks testing every credible option for Windows: browser tools that run in Edge, desktop apps you can install, the built-in Windows 11 feature, and paid options for people who need production speed. This is the honest breakdown.

"Windows is 70% of the global desktop market. Any 'best background remover' list that doesn't address Windows specifically is serving half its audience poorly." — What we learned testing 9 tools across 40 product photos

First: What Windows Actually Gives You for Free

Before you download anything, know what's already on your machine. Windows 11 has shipped a built-in background removal feature since the 2023 update. It lives in the Photos app.

1

Open your photo in Photos

Double-click any JPG or PNG. Windows opens it in the Photos app by default.

2

Click "Edit image" or right-click

You'll see a "Remove background" option in the toolbar. In some builds, right-click the image and look for it in the context menu.

3

Wait for the AI

Windows processes the image locally. It takes 2–5 seconds for a typical photo.

This feature is genuinely useful for one-off personal photos. But it has real limitations that make it unsuitable for business use:

✓ Where Windows built-in works

Simple portraits with clear backgrounds. Product shots on solid white. Quick social media posts. No internet required. No upload.

✗ Where it falls apart

Fine hair detail. Transparent edges. Batch processing. Refining a selection. Exporting at high resolution. Anything beyond one image at a time.

If you're processing more than two images a week, or you need clean edges for client work, you'll want something better. Here are the real options.

The Browser-Based Winner: SmartImgKit

Here's the thing about Windows and modern browsers: Edge and Chrome both support WebAssembly, which means AI models can run directly on your PC — no install, no app store, no cloud upload. This is a game changer because it solves the exact problem that killed remove.bg: you don't depend on someone else's server staying alive.

SmartImgKit's background remover runs the MODNet segmentation model entirely in your browser. On a Windows 11 machine with 8GB of RAM, it processes a 2000×2000 product photo in about 3 seconds. The Desktop App Option: GIMP (Free)

GIMP is the free, open-source Photoshop alternative that runs natively on Windows. It's been around for 20 years and is never going to shut down. Since version 2.10.30, GIMP includes a built-in AI background removal plugin that uses the same U2-Net model powering many commercial tools.

The trade-off is complexity. GIMP has a steep learning curve, and the AI removal requires setting up the plugin and downloading a model file (~170MB). If you already know GIMP, this is unbeatable. If you don't, the browser tools will be faster to adopt.

Install path: Download GIMP from gimp.org, install the "Remove Background" plugin via the Filters menu, and download the U2-Net model on first use. Total setup time: about 15 minutes.

The Commercial Option: Adobe Photoshop (If You Already Have It)

Nobody's going to recommend buying Photoshop just to remove backgrounds. But if your company already pays for the Creative Cloud subscription, Photoshop's "Select Subject" and "Remove Background" button are the gold standard for quality. They handle hair, fur, glass, and complex edges better than any free tool we tested.

On Windows, Photoshop runs best on machines with a discrete GPU. It will struggle on older integrated-graphics laptops. If you're on a Windows 10 machine with 8GB RAM, stick with the browser option.

What About Third-Party Windows Store Apps?

Search the Microsoft Store for "background remover" and you'll see dozens of apps. We tried three of the top-rated ones. Here's what we found:

  • Most are wrappers around the same cloud API. You're paying $3–$5 for a UI that calls a free web service anyway.
  • Ads are aggressive. The free versions show full-screen ads between images. The "pro" versions cost more than a year of Canva.
  • Privacy is opaque. Nearly all of them upload your images to an undisclosed server. Read the permissions before installing.
  • Updates are rare. Many haven't been updated since 2022 and still reference remove.bg as their backend — they'll break on December 1.

Skip the Windows Store for background removal. Every paid app there is worse than a free browser tool.

Questions Windows Users Actually Ask

Does SmartImgKit work on Windows 10?

Yes. Windows 10 ships with an up-to-date Edge browser that supports WebAssembly. The only requirement is a 64-bit version of Windows 10 (build 1903 or later). 32-bit systems are not supported by the AI model, but fewer than 1% of Windows users are still on 32-bit builds.

Will my images be uploaded to a server?

No. The AI model runs as WebAssembly code inside your browser. Your image is processed entirely in RAM on your local machine. Nothing is sent over the network. This is fundamentally different from remove.bg, which uploaded every image to its servers for processing.

Can I use it offline?

After the initial page load, the AI model file is cached by your browser. If you revisit the page without an internet connection, the tool will still work because the model runs locally. This is a major advantage for remote workers and users on spotty connections.

What image sizes are supported?

There is no hard limit on resolution. Very large images (over 4000×4000) may take longer to process and require more RAM, but the tool will handle them. Output is a full-resolution transparent PNG, suitable for print and high-DPI screens.

Can I use this for commercial product photos?

Yes. The tool is free for both personal and commercial use. There is no watermark, no attribution requirement, and no restriction on how you use the resulting images. You can use the cutouts in Amazon listings, Shopify stores, Etsy shops, and client deliverables without any licensing concerns.

What if the edge isn't perfect on hair?

For complex hair or fur, you can open the resulting PNG in GIMP or Photopea and refine the alpha channel manually. For most product photos and portraits, the automatic result is good enough to use immediately. For professional photography workflows, pair the automatic removal with a manual touch-up step in your editor of choice.
