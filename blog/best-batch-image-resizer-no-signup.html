Common mistakes to avoid when batch resizing

  1. Stretching images to exact dimensions: Always lock aspect ratio. If you force a 4:3 product photo to a perfect 1:1 square, it will look squished and distorted. The tool automatically adds white padding on the sides instead, which matches Amazon and Etsy's standard requirements.
  2. Resizing too small: If you're making product photos, don't resize below 1000px on the shortest side. Amazon requires at least 1000px to enable the image zoom feature, which studies show boosts conversion by 15-20% because customers can inspect details.
  3. Using cloud tools for sensitive images: If you're resizing customer photos, internal screenshots, or unreleased product assets, use a local tool. Uploading them to a server means that data could be stored, leaked, or scraped.
  4. Resizing after compressing: Always resize first, then compress. Resizing a compressed JPG adds extra quality loss — start from your original master photos every time.
